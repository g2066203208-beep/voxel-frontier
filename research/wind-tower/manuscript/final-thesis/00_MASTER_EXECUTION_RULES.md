# 最终论文重构最高执行规则

## 1. 目标

在R2Z74真实基础上，将论文改造成一篇能够经受导师、盲审和答辩追问的优秀硕士学位论文。

不是文字润色任务，而是科学内容重构任务。

## 2. 证据原则

任何实质性研究内容必须对应至少一种：
- REF：同行评议论文/学位论文；
- STANDARD：标准；
- OFFICIAL：软件/数据官方文档；
- SOURCE：研究对象原始来源；
- RUN：本文真实计算；
- FIG/TAB：本文真实图表。

没有证据的参数、方法、阈值和结论不得保留为final。

## 3. 文献使用

对核心方法文献必须记录：
研究对象、软件/模型、边界条件、建模步骤、参数、验证指标、比较对象、结果、局限；
并分别说明：
原文做法 → 本文采用 → 本文修改 → 禁止照搬。

不得用“参考某文献”代替方法提取。

## 4. 原稿处理

A 正确且有证据：保留并专业化。
B 思路正确但粗糙：用真实文献方法重构。
C 方法合理但证据不足：补证据。
D 参数无来源：HOLD，查来源或重新设计验证。
E 模型能力与结论不匹配：降低结论或升级模型。
F 历史错误路线：删除。
G 无真实RUN的精确结果：不得写成final。

## 5. 研究主线

场址背景 → 随机整机载荷 → 多指标控制工况 → 精细结构需求 → 控制部位 → 控制机制 → 参数敏感性 → 结构优化 → 独立验证。

禁止写成软件流水账。

## 6. 疲劳分级

G7A：load time history → rainflow → DEL，仅用于疲劳载荷比较和控制工况筛选。

G7B：局部材料应力时程 → rainflow → 材料S-N/mean stress/prestress → Miner → damage/life。
未闭合G7B时禁止写“20年寿命”。

## 7. 非线性

必须在同一输入下做受控对照：
- linear；
- P-Δ/NLGEOM；
- material nonlinear；
- contact/joint nonlinear（仅真实模型支持时）。

没有显式contact时禁止解释COPEN/CPRESS/滑移/开口面积。

## 8. 载荷映射

OpenFAST→Abaqus必须独立V&V：
自由体、坐标、参考点、作用点、力矩运输、时间戳、RNA重力/惯性分账、ΣF、ΣM、跨模型QoI。

## 9. 优化

控制机制 → 敏感性 → 变量/范围/约束 → DOE/代理（条件）→ Pareto/候选 → 高保真回算。
算法不先于物理问题。

## 10. 每节必须给出

研究问题；
原稿问题；
文献依据；
原文具体做法；
本文做法；
实际输入；
验证；
真实结果；
物理解释；
下一章输出；
状态：PASS / CONDITIONAL / HOLD / NEED-RUN / NEED-SOURCE。

## 11. 最终写作顺序

第二章V&V
→ 第三章风环境与整机
→ 第四章映射与控制区域
→ 第五章机制与敏感性
→ 第六章优化
→ 回写第一章研究不足/创新
→ 摘要
→ 第七章结论。

任何阶段稿都必须保存在本工作区并带状态，不覆盖历史证据。


## 12. 步骤级引用准入门禁

任何新研究步骤、公式、参数、工况、模型简化、验证指标或算法，在进入 `chapters/` 正文前，必须先在：

`evidence/STEPWISE_METHOD_EVIDENCE_MATRIX.tsv`

建立对应条目，并至少给出：

- primary GitHub REF；
- 原文/官方真正怎么做；
- 本文采用方式；
- 禁止照搬内容；
- 当前gate状态。

若不存在直接来源，则必须标记 `NEED-SOURCE` 或“本文研究设计+V&V”，不得先写成final正文。

引用完整性检查见：
`evidence/CITATION_INTEGRITY_REPORT_20261005.md`。

特别规则：
- 方法/参数需要REF/STANDARD/OFFICIAL；
- 本文结果需要RUN/FIG/TAB；
- 机理解释需要RUN+REF；
- 文献不能替代本文计算结果。
