# 48 — 钢筋体系来源闭合决策（2026-10-06）

状态：**SOURCE HIERARCHY FROZEN / MODEL VALIDATION PENDING**

原则：何泽瑜2024学位论文是158 m原型的一级来源；原CAE是实现证据，不自动等于正确；规范用于补足原文未公开的构造要求；同研究谱系论文只能补充，不能冒充何论文直接参数。

## 1. 普通纵筋

何泽瑜2024直接支持：
- Abaqus混凝土塔内部采用桁架单元模拟钢筋网；
- 钢筋网嵌入混凝土三维实体；
- 表3-2逐段给出31个混凝土塔节内/外排纵向钢筋数量；
- 第4章按实际纵筋数量与位置建立验证模型。

当前模型：
- 31组RBLONG；
- 5440根T3D2；
- 内外双排；
- 31/31 Embedded；
- 数量与何表3-2一致；
- 几何审计未发现纵筋越出混凝土壁厚。

因此：
- **纵筋数量/层数/T3D2+Embedded：可保留。**
- 当前490.874 mm²/根（等效约φ25）是源输入事实，不是何论文公开直接参数。
- 在找到同一158 m原型的原始CAE/JNL/设计表前，禁止把“φ25”写成何论文设计值。

## 2. 普通环向筋/箍筋

何泽瑜2024直接支持：
- Abaqus中存在“钢筋网”建模概念；
- 第4章明确讨论箍筋作用，OpenSees中因直接模拟困难采用约束混凝土近似。

何论文**未公开**：
- 本158 m原型箍筋直径；
- 轴向间距；
- 拉筋直径/间距；
- 精确保护层和环筋半径。

因此：
- T046的HRB335 φ14@80 + φ6拉筋只能是**规范推导候选**，不能当作原型最终配筋。
- 原始CAE中的RHOOP资产也只能作为**原实现候选**，不能因“原CAE存在”直接判定正确。

正式解决路线：
1. 从原始CAE/JNL提取每个RHOOP Part的section、area/diameter、材料、节点坐标、环向/竖向间距、实例抑制状态；
2. 检查是否位于混凝土壁厚内、是否满足保护层、是否与纵筋形成双层钢筋网、是否存在重复约束；
3. 对照GB 50135—2019 / GB 50010 / T/CEC 5008的最小直径、最大间距、最小配筋率、拉筋与保护层要求；
4. 只有“原CAE实现 + 规范验算 + Abaqus data check/Gravity/Modal”同时通过，才升级为正式箍筋模型；
5. 若原RHOOP不满足规范或属性不完整，则保留何论文能证明的钢筋网身份，按规范重新设计并明确标为“本文补全”，不冒充原型参数。

## 3. 预应力筋

何泽瑜2024直接支持：
- 15.2 mm钢绞线；
- 采用桁架单元表示；
- PT底端固定；
- PT顶部固定到钢—混转换钢法兰；
- 图示为沿圆周布置的多根PT。

同研究谱系Xu/He等2025补充：
- externally unbonded；
- E=195 GPa；
- fy≈1320 MPa，fu≈1860 MPa；
- 初始预应力1280 MPa。

当前仍非何论文直接公开：
- 36的位置/数量身份；
- 每个位置是1股还是1束；
- 单位置有效面积；
- r=1.75 m。

因此：
- **15.2 mm、外置无黏结、端部锚固、E=195 GPa、1280 MPa可作为当前对象级建模链。**
- “36 × 140 mm²”不得在束组歧义关闭前作为最终总预应力冻结。
- “r=1.75 m”继续标记为源输入继承参数，不写成何论文直接值。

## 4. 当前结论

- 纵筋：**几何数量与约束基本闭合；截面面积来源待关闭。**
- 箍筋：**何论文确认“应有钢筋网/箍筋作用”，但不给直径与间距；必须审计原RHOOP后再决定。**
- PT：**类型、材料与端锚方式基本闭合；束组倍数和半径仍为HOLD。**

在上述HOLD关闭前，任何网页、论文或模型说明不得写“全部钢筋参数已按何泽瑜论文直接复现”。

## 5. 2026-10-06 原始 RHOOP 资产核对升级

T038 原生只读审计已经从用户原 CAE 中直接确认：

- 每个被审计模型均存在 31 个 `RHOOP_*` Part；
- 每模型合计 32712 个 T3D2 环筋单元；
- 截面名为 `SEC_REBAR_HOOP`；
- 材料为 S345；
- 对应 31 个装配实例全部处于 suppressed；
- 因此当前活动装配中的 RHOOP 有效节点/单元为 0。

这意味着“用户没建箍筋”是错误说法；准确说法是：

> **原始 CAE 已建立并网格化环向钢筋资产，但所读生产装配中这些实例被全部抑制，当前正式基线没有让它们参与求解。**

上述事实仍不能证明原 RHOOP 的截面积、直径、竖向间距、半径、保护层、Embedded host 和恢复后力学行为正确。

为关闭这些项目，新增 T049 只读提取器：
`research/wind-tower/experiments/T049/extract_rhoop_details.py`

它将逐 Part 输出 section area/等效直径、材料、闭合环组件、标高、半径、竖向间距、实例抑制状态以及 RHOOP Embedded 关系。源 CAE 运行前后 SHA256 必须一致。
