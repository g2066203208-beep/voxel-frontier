# T045 当前 RNA 简化：计算身份、叶片去向与网页显示边界

日期：2026-10-06  
状态：**ACTIVE-CALCULATION-IDENTITY / SOURCE-RNA-VISUAL-OVERLAY-SEPARATED**

## 1. 一句话结论

当前 T045 的 Abaqus 求解 RNA **不是“只有质量的一个点”**，也不是网页上看到的三片叶片/机舱表面网格。

正式计算采用：

[
\boxed{\text{MASS}+\text{完整 ROTARYI}+\text{偏心 CG}+\text{6DOF 运动学耦合}}
]

也就是把 OpenFAST R2 冻结状态下叶片+轮毂+机舱的**总质量、质心和三维转动惯量**压缩成一个空间刚体惯性算子，再偏心连接到物理塔顶 O158。

塔顶到CG：
- `*Coupling, constraint name=CPL_RNA_R2_EQUIV, ref node=SET_TOWER_TOP_O, surface=SURF_RNA_R2_EQUIV_CG`
- `*Kinematic`

因此它保留了：
1. RNA总质量；
2. 偏心质心；
3. 完整三维转动惯量（包括积惯量）；
4. 塔顶平移—转动与RNA惯性之间的空间耦合。

它不等于只给塔顶一个 `m` 的 scalar point mass。

## 4. OpenFAST → Abaqus 的等效来源

R2 OpenFAST冻结质量属性由实际 ElastoDyn/机组输入重建：
- nacelle：446036.25 kg；
- hub：105520 kg；
- 3片叶片：按实际Blade输入线质量积分；
- 重建RNA总质量：676753.290723 kg；
- ED.sum塔顶质量：676753.250 kg（仅约0.041 kg舍入/重建差）。

坐标映射：
- OpenFAST IEC x → Abaqus +Z
- OpenFAST IEC y → Abaqus +X
- OpenFAST IEC z → Abaqus +Y

T038已对空间质量算子做独立数值验证：
- 6×6质量矩阵块归一化最大误差约3.699e-16；
- 重力反力/反力矩归一化最大误差约3.308e-08；
- 规定运动动能归一化最大误差约3.608e-07。

这些验证证明“空间质量算子在Abaqus中的数值表达正确”，**不证明叶片柔性/转动气动问题由Abaqus承担**。

## 5. 为什么这样简化有文献依据

- Xing et al., Frontiers in Built Environment 2026（DOI 10.3389/fbuil.2025.1728006）对约160 m在役混塔的精细Abaqus模型明确采用“偏心点质量 + 转动惯量”RNA，并耦合到塔顶；其模型经运营模态数据验证。这是本文塔架低阶动力研究采用空间惯性等效RNA的直接同类先例。
- Wang et al., JMSE 2026（DOI 10.3390/jmse14100956）将RNA分为DPM、MPM、CPM，明确指出只保留标量质量的CPM会遗漏转动惯量；保留质量+转动惯量的表示比简单单点质量更完整。但简化模型不能恢复叶片局部模态/柔性。

因此本文的Abaqus RNA定位为：
**塔架低阶结构响应所需的空间惯性等效，不是Abaqus内的整机气弹模型。**

## 6. 叶片柔性、旋转、气动力由谁承担

正式论文路线中：
- **OpenFAST + ROSCO**：承担真实叶片柔性、转子旋转、气动力、控制、整机随机风载荷；
- **Abaqus**：承担精细混塔结构和RNA空间惯性；
- OpenFAST→Abaqus接口传递经自由体审计后的塔顶/分布载荷。

所以不能要求Abaqus这个RNA质量算子本身再次生成叶片气动力、变桨、转速或叶片模态；否则会和OpenFAST职责重复。

## 7. 仍需保留的能力边界

当前RNA等效适合：
- 重力；
- 塔架低阶模态；
- 塔架整体位移/内力；
- OpenFAST外载驱动下的精细塔架响应。

不直接适合：
- Abaqus内叶片局部应力；
- 叶片柔性模态；
- 转子陀螺/旋转气动由Abaqus自发产生；
- 机舱内部局部受力；
- 高阶叶片—塔架耦合模态。

如论文QoI扩展到这些目标，必须升级RNA模型，而不是继续把空间惯量等效模型外推。
