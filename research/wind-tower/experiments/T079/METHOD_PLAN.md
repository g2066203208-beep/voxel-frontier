# 嘉鱼10 MW预应力钢混塔：地震与风震研究方案

日期：2026-10-21。对象：DTU 10 MW参考机组、何泽瑜2024来源的158 m混塔、嘉鱼研究场址。

**结论：保留现有风环境—风荷载—疲劳主线，增加地震响应和风震联合响应研究，并设置独立的抗震验算表。先统一配筋与求解模型，再验证RNA地震适用性，然后开展真实记录时程。**

本次完成工作室状态核查、文献检索和方法设计；没有运行本塔地震算例，没有产生地震云图或抗震合格结论。下文数字明确区分“既有记录”“城镇级参数”“研究假设”和“拟开展工况”。

## 2. 嘉鱼场址参数：哪些能确定，哪些只能暂设

### 2.1 已核实的城镇级基准

GB/T 50011-2010（2024年版）附录A湖北省表列嘉鱼县为：**6度、设计基本地震加速度0.05g、第一组**。这是县级城镇建筑抗震参数基准，不等于已完成本研究坐标的场址地震安全评价。[附录A原始来源](https://gf.cabr-fire.com/article-15954.htm)

本次保存并查看了[湖北表原图](https://gf.cabr-fire.com/Web/uploads/allimg/230914/153403I32-34.jpg)。2024版标准名称与编号调整可查[住建部公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2024/art_17339_778179.html)。

## 4. 论文需要回答的四个问题

1. 嘉鱼这一地震水准下，哪些指标由风控制，哪些可能由地震或风震共同作用控制？不预设“地震一定更危险”。
2. 同样满足刚体质量、质心和惯量的RNA简化，对塔顶加速度、过渡段剪力、基底弯矩是否仍可靠？
3. 风致初始弯曲、长期有效预应力与分段接缝如何影响地震过程中的失压、开缝和残余状态？
4. 原疲劳优化方案是否仍满足新增地震约束？如果不满足，修改哪些设计变量才有证据？

## 5. 六步实施路线

### 第一步：统一研究模型并冻结版本

保留“何论文复现模型”和“规范重新设计模型”两个身份。正式地震生产使用同一经过验收的设计模型；不得把复现的HRB335结果与HRB500设计表合并成同一个完成状态。

冻结清单：31段几何、材料、内外排纵筋、环筋/拉筋、钢塔、接缝、基础、预应力路径、RNA质量/质心/惯量张量、局部轴、单位和源文件哈希。已有长期有效预应力已扣损失，不能再次重复扣除五类损失。

先完成重力＋长期有效PT平衡，检查反力、接触状态、31段截面轴力与弯矩；再提取该平衡态的多阶模态。需要核对振型对应关系与质量参与，不能只对着模态序号比较频率。模型输出包括CAE/INP、Data Check日志、平衡表和原生截图。

### 第二步：补RNA地震适用性验证

- R0：现有MASS＋ROTARYI＋偏心质心＋6DOF耦合。
- R1：同一塔架、机舱刚体＋按DTU截面刚度/质量分布校准的柔性梁叶片；先核对总质量、质心、惯量和叶片模态。
- 初试拟采用3组真实记录对、2个水平朝向、2个RNA模型，形成12个拟验证算例。
- 对比多阶频率/振型、有效质量、塔顶相对位移和绝对加速度、基底及钢混过渡段剪力/弯矩。
- 可预先设频率5%、主要峰值10%作为本研究筛查线，并附时程/振型判断；这是研究阈值，不是规范合格线。超出即保留R1或收窄R0适用范围，不能调参掩盖误差。

RNA惯量必须注明关于质心还是塔顶；平行轴搬移仅做一次。梁叶片、机舱外壳与集中质量不能重复计重。停机对照不能自动验证旋转叶片、陀螺效应与运行控制反馈。

### 第三步：建立真实地震记录及谱核查台账

先3组试流程，候选研究以7组配对记录作为起点；记录数与统计规则最终按采用标准和目的确定，不把“7组”写成所有风机通用的强制下限。

从[PEER官方数据库](https://peer.berkeley.edu/peer-strong-ground-motion-databases)等可信来源取真实记录，保留同事件、同台站的水平配对。元数据至少含记录ID、事件、台站、震级、距离、场地、分量、步长、时长、单位、处理/滤波参数、最低可靠频率和缩放因子；数据库需登录的下载不得以虚构记录替代。

选配窗口必须覆盖影响塔架响应的低阶与高阶周期，并考虑土柔性或非线性周期延长。先检查低频可靠性，再检验目标谱均值和记录离散性；不只统一PGA。避免对已处理记录重复去趋势、高通滤波而消除真实长周期能量。原始、处理后与缩放后文件分别存档。[PEER用户手册](https://ngawest2.berkeley.edu/peer_ground_motion_database_users_manual.pdf)

### 第四步：反应谱筛查与停机地震时程

先固定停机/顺桨/叶片方位，进行反应谱筛查，确定关键频带和截面；随后做配对水平时程。模态截断以质量和关键响应收敛共同判断，密集模态采用适当相关组合。

Abaqus线性支路：平衡态→Frequency→Modal Dynamic主基底输入；U/V/A为相对主基底量，TU/TV/TA为总运动。塔顶设备加速度用绝对量，不能将相对A直接冒充绝对加速度。[官方模态文档](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEANLRefMap/simaanl-c-modaldynamic.htm)

非线性直接积分支路使用适当的基底运动边界，例如TYPE=ACCELERATION；替换对应原固定自由度，核对初速度与单位，不能把模态BASE MOTION直接移植，也不能同一自由度同时固定和施加地震运动。[官方边界文档](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEKEYRefMap/simakey-r-boundary.htm)

用一个已知解小模型和同一小震下的模态/直接积分对照校验输入；再做时间步减半、模态数增加及关键区网格敏感性。以关键指标变化约5%作为预设工程数值筛查目标，明确它不是规范条文。

### 第五步：风震联合时程与运行状态

本节3个运行风种子和1个停机风种子仅为初步算法/响应筛查预算，不是正式规范验算矩阵。既有REF132对一般湍流计算随机实现数已有审计，正式风震组合须重新核对适用条款并做样本收敛；不能用本候选215条目宣称达到IEC样本要求。

沿用嘉鱼ERA5得到的长期风环境，再通过现有TurbSim/OpenFAST流程生成秒级风场和整机载荷。逐小时ERA5不能直接充当湍流或地震加速度。代表风速从DTU当前模型实际推力曲线选择，优先额定附近或最大推力附近，不照搬其他机型额定风速。

首轮分别做停机无风E、运行W、停机背景风W、运行W＋E和停机背景风W＋E。正常运行采用3个可复现风种子；风响应进入稳定统计状态后输入地震，保留相同风序列的无震对照。方向先0°/90°，控制组合追加45°及地震开始时刻敏感性。竖向分量在代表工况筛查预应力、压紧和轴力影响；正式规范组合不能因筛查安排而漏掉所需分量。

**风载接口必须先查清楚。** OpenFAST塔顶YawBr六分力含接口惯性贡献，不能在保留完整RNA质量的Abaqus模型里未经分解直接当纯气动力叠加。建立每个力/矩的物理组成、作用点、方向、单位、重力/惯性包含情况，先验证无风重力、已知静推力、无风地震三项平衡。[OpenFAST官方源码](https://github.com/OpenFAST/openfast/blob/main/modules/elastodyn/src/ElastoDyn.f90)

本研究首选“独立外部风荷载传递＋识别的等效气动阻尼”路线。它属于一向联合时程或弱耦合近似；只有真实交换结构运动、气动力及控制反馈并完成验证，才称全耦合。结构阻尼与气动阻尼分开记录，运行/停机、FA/SS方向分别处理；若气动反馈已经显式计算，不重复增加等效气动阻尼。

紧急停机作为后续分支，需经验证的触发、变桨、转速和控制器过程，不能通过瞬间删除风载模拟。不能将极端湍流峰值与罕遇地震不加解释地绑成设计工况；联合发生、组合依据及研究敏感性三者分清。

### 第六步：控制工况精细非线性与抗震验算

从不同控制指标选6—12个代表工况进入精细模型，分别覆盖塔底弯矩、过渡段剪力、接缝失压和筋材需求；不只选最大塔顶位移。该选择不替代所有规范所需工况，也不用于宣称完整概率易损性。

要研究接缝开闭，必须具备适当接触、预压和滑移/摩擦模型；永久Tie模型只能做相应弹性整体筛查。混凝土循环损伤、筋材塑性、无粘结预应力路径等需物理依据和数值验证。钢塔局部屈曲结论需要相应壳模型及缺陷处理，梁模型不能输出不存在的局部失稳。

抗震验算另建逐项清单：截面轴弯承载、剪扭、筋材应力/应变、接缝及连接、整体稳定、变形、基础和锚固等；限值和系数逐条注明标准及适用性。未闭合地勘、配筋或材料依据的项目标待验证，不据一张Mises云图判定全塔抗震合格。

| 候选筛查一个地震水准：运行风震 | 7记录对×2朝向×3风种子 | 42 |
| 候选筛查一个地震水准：停机背景风震 | 7记录对×2朝向×1背景风种子 | 14 |
| 三个水准主矩阵 | 每水准70组×3 | 210 |
| 基准 | 运行无震3组＋停机背景风无震1组＋G/PT初态1组 | 5 |

先完成一个水准的70组和5个基准，再扩展到三个水准；主矩阵合计215个计划条目，RNA流程验证另列。只在经过验证的整体模型上批量运行，6—12个精细非线性案例另行筛选。多风速、竖向、SSI、预应力不确定性、45°和触发相位均作为有依据的增补，不同时展开庞大全因子矩阵。

工况预算需经方法全文和规范适用性核对后调整；3个风种子不视为统计充分。对应机器可读计划见[planned_cases.json](planned_cases.json)。其中GM01—GM07和风种子槽位是**尚未绑定真实输入的计划标签**，不是地震记录ID或已运行风种子。所有条目的 `ready_to_run=false`。

## 7. 必须得到哪些真实图表

| 证据 | 输出内容 | 能回答什么 |
|---|---|---|
| 模型初态 | 质量/质心/惯量、预应力、反力、31段压紧表；模型原生截图 | 新模型确实按设计建立 |
| RNA对照 | 多阶模态、振型及同波时程误差 | 简化在哪些指标和频带可用 |
| 输入审核 | 记录台账、原始/处理时程、目标谱与记录谱、缩放因子 | 地震输入真实且适配 |
| 风/震/风震对比 | 塔顶相对位移、绝对加速度；基底及过渡段N/V/M/T | 哪种作用控制哪项响应 |
| 沿高需求 | 31段端部及中部关键截面内力包络 | 控制位置是否从塔底转移 |
| 接缝/预应力 | COPEN、接触压力、滑移、钢绞线峰值及残余力 | 接缝与长期有效预应力的作用 |
| 非线性结果 | 残余位移、材料响应、能量平衡及适用时的震后模态 | 损伤与残余性能是否有证据 |
| 验算汇总 | 同时刻组合内力、需求/承载力、标准条款、通过或待验 | 把响应结果转化为可审查验算 |

均值、离散性和最大值分别报告；每个极值带时间、位置、记录和工况。不能把不同时间的N、M、V最大值拼成一个“同时发生”的状态。云图和动画由实际ODB生成，注明物理量、单位、时刻、变形放大倍数、色标和模型哈希；没有求解结果就不绘制结果示意充数。

## 8. 与风疲劳和论文目录的衔接

长期风疲劳仍按风环境概率、运行时长、雨流计数和经确认材料方法求解。地震首先研究极端需求、接缝、残余变形和损伤；单次地震不能直接按每年固定循环塞入Miner寿命。发生显著塑性时，应采用相应循环材料和低周损伤依据，不能把高周S-N无条件外推。

后续可研究“震后残余状态下，同一风载的局部响应是否变化”，但需要真实损伤状态传递；未建立地震发生率与退化/修复模型前，不宣称统一全寿命已完成。
