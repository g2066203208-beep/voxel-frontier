# 第三步附件：RNA共同坐标、参考点与惯量方法审查

日期：2026-10-05。本步仅形成统一表与修订方案，不修改模型、不启动求解。仓库起始快照为 `7c05ea7355fa623f863a3cf11d0908a83cb94f41`。本附件区分实际M2算子、可从R2原生代码重建的冻结构形算子、真实物理RNA属性，不用其中一项冒充另一项。

## 1. 可以在本步算什么

当前M2的质量、质心和B31离散惯量可以完整重算。R2 ElastoDyn在明确锁定姿态及内部相对自由度后，其代码采用的质量点和惯性方向项也可以组装为6×6动能算子；机舱、轮毂某些方向在代码中省略，并不妨碍重建这个**软件模型的限制算子**。但这种省略不是实物相应惯量已测为零，不能由软件算子进一步宣称取得了完整物理RNA真值。

本步共同参考点建议采用未变形塔顶O，Abaqus全局坐标为 `(0,158,0)` m。原RNA参考点P=`(0,160,0)` m作为已存在的模型控制点保留其身份。比较质量算子不要求先移动节点；先把两侧算子变换到同一点和同一坐标基即可。

## 2. 坐标证据和本步条件映射

Abaqus实际输入以+Y为竖直，重力为−Y。M2的轮毂质量环和三叶片均在Z≈−7.1 m的平面，轮毂中心约 `(0,160,−7.0999999)` m；机舱载体质心约 `(0,160.449997,2.687000155)` m。这些节点证明转子在−Z侧、机舱质心在+Z侧；轮毂平面的无向法向为±Z。来源为M2输入第62803–62865行及 `abaqus-results/abaqus-rna-properties.json`，其输入SHA为 `428a8bb567a52200311ebb1a2019a71c304d1c427ce761f0c836e4fc46fe50f1`。

OpenFAST v3.5.3固定源码提交为 `6a7a543790f3cad4a65b87242a619ac5b34b4c0f`。`ElastoDyn.f90` 第6004–6006行明确：内部向量数组的三个基方向是 `(IEC x_i, IEC z_i, −IEC y_i)`。因此不能因内部数组第二分量竖直，就将其直接当Abaqus全局数组。对外IEC坐标与内部数组是不同表达。

定义F为OpenFAST/IEC参考基、A为Abaqus全局基，均为右手系。基于两侧已知的轮毂上风侧、机舱下风侧及竖直方向，本步可采用以下**零偏航名义姿态的几何对齐候选**：

```text
e_xF → +e_ZA    e_yF → +e_XA    e_zF → +e_YA

                 [0 1 0]
v_A = R₀ v_F, R₀=[0 0 1], det(R₀)=+1, R₀ᵀR₀=I。
                 [1 0 0]
```

这是由对象两侧的几何语义形成的明确研究对齐约定，不是仅按轴字母猜换位。它足以完成本步条件比较。**历史风场方向、运行输出通道与Abaqus载荷映射脚本尚未闭合，故不能把R₀写成历史生产接口已经证实使用的矩阵。** 下一步若沿用，应把该约定写入映射器，并以重力、单位风向力和力矩虚功核验。

IEC向量到ElastoDyn内部数组的矩阵为：

```text
   [1  0 0]                    [0 0 -1]
C= [0  0 1], v_ED=Cv_F；RCᵀ= [0 1  0]。
   [0 -1 0]                    [1 0  0]
```

非零机舱偏航时，机舱局部向量先经其真实姿态矩阵 `Q_n→F`，再用 `R₀Q_n→F`；不能把机舱局部输出或旋转叶根输出直接套R₀。全局基间的R₀与机舱实时姿态变换不是同一个矩阵。时间变化坐标下的动力学还涉及姿态及速度项，不是静态旋转一个张量即可完成。

## 3. 原点、轮毂和机舱不能用一次平移强制重合

坐标位置统一写作 `x_A=t+R₀x_F`。若两模型塔基原点对齐，t=0；若从各自塔顶相对坐标出发，则写为 `x_A=O_A+R₀(x_F−O_F)`，其中 `O_F=(0,0,158)` m。同一式子不能同时加入t和再次加入塔顶高度。

R2名义姿态由已核输入给出：零偏航、三叶、Furling=False、HubCM=0、UndSling=0，TowerHt=158、Twr2Shft=2.75、OverHang=−7.1、ShftTilt=−5°。因此：

|参考位置|IEC/F坐标，m|经R₀变换的A坐标，m|当前M2，m|
|---|---|---|---|
|塔顶O|(0,0,158)|(0,158,0)|(0,158,0)|
|机舱质心U|(2.687,0,160.45)|(0,160.45,2.687)|(0,160.449997,2.687000155)|
|轮毂/转子顶点H|(−7.072982356,0,161.368805774)|(0,161.368805774,−7.072982356)|(0,160,−7.0999999)|
|旧RNA参考点P|仅为Abaqus现有控制点| (0,160,0)|不是轮毂或全RNA质心的自动定义|

机舱已基本重合，轮毂还相差约 `(0,+1.368805774,+0.027017544)` m。因此把整个RNA上移1.3688 m会同时移坏原本相符的机舱位置；不能如此“统一高度”。当前M2转子平面未含R2的5°轴倾与−2.5°预锥，几何差异也不能由一项总质量修补。

官方DTU报告第65–66页给出轮毂、偏航轴和机舱质心的不同参考点；第66页表6.1的119 m轴承标签与正文冲突已在第二步裁决。此处采用已冻结R2输入和源代码位置链，不重新取表格标签覆盖输入。

## 4. 张量和6×6算子的符号约定

统一自由度/速度顺序为 `(Ux,Uy,Uz,URx,URy,URz)` / `(v_x,v_y,v_z,ω_x,ω_y,ω_z)`。旋转以右手规则计，角度使用弧度。定义 `S(r)a=r×a`，惯量张量采用：

`J_G=∫[(s·s)I−ssᵀ]dm`。

所以非对角量是负积惯量，例如 `J_xy=−∫s_xs_y dm`。不能将“积惯量”一词视为自动说明正负号。

对于质心G、任意参考点P，令 `r=x_G−x_P`，则：

```text
J_P = J_G + m[(r·r)I−rrᵀ] = J_G + m S(r)ᵀS(r)

v_G = v_P + ω×r = v_P−S(r)ω

M_P = [ mI     −mS(r) ]
      [ mS(r)   J_P   ]

T = ½ [v_P;ω]ᵀ M_P [v_P;ω]
  = ½ m|v_G|² + ½ ωᵀJ_Gω。
```

平移—转动耦合块符号由速度关系推导；不能仅根据矩阵是否对称决定符号。三个块的单位分别为kg、kg·m、kg·m²，不对整矩阵混合单位元素做一个未经归一化的百分比。

从旧点P转到新点O，令 `a=x_P−x_O`，则：

```text
[v_P;ω] = H(a)[v_O;ω], H(a)=[I −S(a);0 I]
M_O=H(a)ᵀM_PH(a)。
```

仅改变坐标基、保持同一物理参考点时，`J_A=RJ_FRᵀ`；令`T_R=diag(R,R)`，则`M_A=T_RM_FT_Rᵀ`。改变参考点和改变坐标基是两个不同操作，必须记录次序及其所用的向量基。

力和力矩采用同一点上的功率对偶：

`F_A=RF_F`，`M_O^A=R M_P^F+(x_P^A−x_O^A)×F_A`。

此处的M是力矩，不是质量矩阵。接口还需确认该力矩究竟是“上部作用于塔”还是反力的相反侧；坐标旋转不能替代作用反作用符号审定。

## 5. 当前M2与历史离散/连续结果怎么用

本步脚本实际输入取自当前M2独立积分JSON，不再用历史G1示例作为当前数值来源。M2实算RNA约673998.493138 kg，质心约 `(0,160.297797698,−0.623184005)` m。相对塔顶O的偏心为 `(0,2.297797698,−0.623184005)` m；相对旧P只在第二分量减少2 m。

因此塔顶M6的两个显著上右块为 `M[Ux,URy]≈−420025.0805 kg·m`、`M[Ux,URz]≈−1548712.1863 kg·m`。M2质心 `J_yz≈−664405.3751 kg·m²`，搬移至塔顶后 `J_yz≈+300727.2882 kg·m²`；变号有正确的平行轴来源，不应手工强改回负号。

现有B31的端点集中质量与连续均匀杆具有相同m、G，但J不同。每段均匀直杆的差为 `ΔJ=mL²/6(I−ttᵀ)`。已存在的G1/RUN036空间MASS+ROTARYI替换试验验证的是旧B31离散算子的数值等价；RUN037连续杆惯量分支是表示敏感性。两者都不提供独立风机物理真值。本步重新核M2输入及DAT，未重跑这些试验，也不将旧G1求解直接称为已做M2替换求解。

惯量序列必须按接口区分：旧已校验CAE查询为`xx,yy,zz,xy,yz,zx`；`*ROTARY INERTIA`输入与DAT本项采用`I11,I22,I33,I12,I13,I23`。不得直接复制六元组而不重排。

## 6. R2原生冻结算子可以如何复算

固定的是审计构形：零挠曲、输入Azimuth=0、NacYaw=0、桨距0；相对GeAz、DrTr以及叶片模态速度均置零来提取共同刚体运动的动能系数。这不是实际9.6 rpm运行状态，也不是把原模型这些自由度的启用标志改为False。

由固定源码可直接使用以下组成，不从别的HAWC2版本补未启用字段：

1. 叶片：当前ED读取分布卡的前6列；`ElastoDyn_IO.f90`第1773、1778、1786–1791行给出列数及赋值。第7列及以后遗留截面转动惯量列不进入这套ED。各中点质量采用实际插值及积分方案；本步OpenFAST专项脚本负责按51个分析点计算，不能拿HAWC2梯形总质量替代。
2. 叶片位置：令`α=ShftTilt`，零yaw/skew/furl时 `s=(cosα,0,sinα)`，`c₂=(−sinα,0,cosα)`，`c₃=(0,−1,0)`。**内部转角为输入Azimuth−AzimB1Up−π/2**（第3654行），不能把输入0°直接作为内部0。按第6093–6095、6133–6156行逐叶旋转得到`j₃,k`，每一质量点位置为`H+(HubRad+RNodes_j)j₃,k`（第6610行）。负预锥使轴向偏移沿−s，不是+s。
3. 机舱：质点质量NacMass位于U，原生方向惯量为 `I_n=NacYIner−m_n(NacCMxn²+NacCMyn²)=4105978.55212375 kg·m²`，其质心方向项为`I_n e_z,n e_z,nᵀ`（第4672、7685行）。横向方向项是该模型省略，真实物理值仍未知。
4. 轮毂：HubMass位于H（HubCM=0），方向项`HubIner·ssᵀ`；三叶情况下另一hub方向项由代码明确设0（第4683–4697行）。该省略不是第三方需要凭空猜出的参数，也不是实物横向惯量确为零。
5. 发电机：源代码第6722–6724行给 `ω_G=ω_N+GBRatio·q̇_GeAz·s`。本审计相对转动锁定后，仍保留 `GenIner·ssᵀ=1500.5·ssᵀ`。`1500.5×50²=3751250`是另一个传动广义坐标的系数，不能加进共同刚体旋转空间算子。发电机质量不另造一个条目重复增加到机舱质量。

把上述质点惯量搬移至共同G，再加各原生方向项，可以得到本构形的完整**软件级限制J和M6**。它不是把缺省物理属性“补齐”为已知；更不是实际运行整机的广义质量矩阵。刚体限制算子的构成已充分明确，可据本步审查结果提出条件修订方案，无需等到所有实物惯量取得后才做软件对齐。

本轮进一步独立采用三叶120°对称性的闭式一、二阶矩核对OpenFAST专项脚本，不复用其逐点位置循环。设单叶质量m_b、对轮毂中心的一阶/二阶径向矩为μ₁、μ₂、预锥β、单位轴向s、塔顶至轮毂向量h，则三叶的原始二阶矩为：

`Q_b=3m_b hhᵀ+3μ₁sinβ(hsᵀ+shᵀ)+μ₂[3sin²β ssᵀ+(3/2)cos²β(I−ssᵀ)]`。

三叶一阶矩为 `3m_b h+3μ₁sinβ·s`。加入轮毂、机舱的质点矩及原生方向惯量后，使用`J_O=tr(Q)I−Q+J_intrinsic`和一次平行轴搬移，得到：

- R2原生冻结质量 **676753.2907231401 kg**；此为float64独立重建值，与归档`ED.sum`676753.250 kg差0.040723 kg，不能伪称已导出的精确求解器矩阵。
- 质心相对塔顶的IEC坐标约 **(−0.872962499,0,2.783588030) m**；映射后Abaqus全局坐标约 **(0,160.783588030,−0.872962499) m**。
- 映射后质心惯量对角约 **(94926999.798112,99481015.620165,155901495.338512) kg·m²**，`J_YZ≈−5231495.690282 kg·m²`；XY、XZ约为数值零。
- 闭式结果与逐点装配JG最大绝对差 **5.96×10⁻⁸ kg·m²**，CG及M6一致。完整数值、文件SHA和检查结果见`coordinate-method-evidence.json`。

已审读`compare_rna_properties.py`：其共同点、R矩阵、质心及张量变换与上述约定一致。质量差+2754.797585 kg、质心距离0.5462431165 m、同单位JG的Frobenius相对差8.72057%均是**两个软件表示在条件对齐下的属性差**；不是运行响应误差、物理验证误差或可接受误差阈值。

柔性旋转整机满足的是包含内自由度的 `M(q)q̈+h(q,q̇)+…=Q`，其中有随构形变化的耦合、陀螺/离心项及弹性势能。`M6`只是明确定义的共同刚体子空间动能限制；不是随意取整机矩阵前6行列，也不是通过静力凝聚便得到全频段动态等效。若内部转动或模态不锁定，所得到的耦合矩阵、状态和降阶规则必须另列。

## 7. 可提交审阅的输入修订形式

建议以一个明确的空间质量输入替代纯质量载体B31，先分两种目的：

- **表示等价副本**：采用当前M2离散m/G/J，目的仅是替换表示，目标是保持既有算子。此目标已完整可算；不能把旧连续杆J或新R2原生J混入后仍叫表示等价。
- **R2原生冻结构形对齐副本**：采用本步由真实R2输入及固定代码重建的m/G/J，明确姿态、内部锁定规则及R₀条件映射。它是改动模型质量属性，必须在下次获准实施后重新检查基态、反力及模态；不借此关闭柔性/旋转运行适用性问题。

建议先形成**独立RNA质量验证小样的修订方案**，在所采用G位置设置一个MASS元素和一个ROTARYI元素，输入**关于G的**完整对称张量，并以6自由度约束连接到共同塔顶参考点O。先审质量、重力力矩、刚体加速度反力与动能；不直接改整塔生产输入。

之后若获准接入M2，可以保留原P=(0,160,0)及既有塔顶传力连接，让G处质量通过正确偏心的6自由度约束连接P；不需要为表面上“对齐”去移动P。已有RUN036实际输入第31061–31073行及第33845–33849行采用这类`CG节点+MASS+ROTARYI+Kinematic 1,6`表达，可作为结构形式参考，数值按本次批准目标重建。必须移除/停用被替代的28个B31质量贡献，避免双计；原RNA可保留为不承载质量的显示几何，但其原质量材料不能同时参与计算。

把一个MASS和J_P直接放在偏心P、却不表示G偏置，会丢失平移—转动耦合和正确重力力矩。也不能在G处填写已搬移的J_P再让刚性约束自动搬移一次。若使用矩阵单元直接输入6×6算子，需另核可支持的Abaqus接口、单位和符号，本步优先采用已有可追溯的偏心节点形式。
