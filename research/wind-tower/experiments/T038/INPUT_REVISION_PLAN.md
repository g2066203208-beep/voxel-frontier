# T038 RNA输入修订方案（提案，未实施）

日期：2026-10-05。对应用户逐步审查的第3步。候选对象：T026 M2与历史R2输入。本文是研究实施方案，不是学位论文正文。

## 1. 本步选择及理由

建议先以**R2真实输入和OpenFAST v3.5.3原生实现所定义的、未变形且内部相对运动锁定的质量算子**建立独立验证小样。目标是验证Abaqus能否准确表达同一组质量、质心和质心惯量。小样通过且经用户审查后，再决定如何接入M2。

这项选择保留原有整机输入来源链，使差异可以定位；它不把ElastoDyn省略的机舱横向惯量或轮毂横向惯量解释为实际物体的零惯量。真实三维组件惯量、叶片柔性、转动、陀螺效应和运行反馈仍需分项验证。

不建议按一个总质量比例缩放现有RNA材料密度：这种操作不能修正质心位置、轴倾角/预锥和离散惯量差。也不建议直接把历史另一分支M6数值填入M2；原文件身份和线性化状态尚未绑定。

## 4. 小样的预定核验及停止规则

1. 固定输入文件、代码版本、矩阵DOF顺序、坐标和状态，记录所有哈希；用同一原始参数生成解析目标和小样。
2. 首先检查质量、质心、JG及搬移至O的JT。量纲分别为kg、m、kg·m²，不设一个混合单位总误差指标。
3. 读取小样的实际求解器质量矩阵或以六个独立单位加速度识别矩阵；对平移块、偏心耦合块和转动块分别比较。接口约束后的矩阵必须对应相同独立自由度。
4. 用至少一组平移与转动混合运动检查动能，用已知重力检查合力与O点力矩。容差根据矩阵输出有效位数与求解器精度预先登记；当前脚本机器精度自检不是物理验收阈值。
5. 如数值不符，先定位坐标、非对角顺序、参考点和重复质量，不调整目标参数去迎合结果。记录失败及修正。
6. 小样核验完成即交审查。未获下一次批准前，不自动修改M2整塔、不启动36工况，也不把D08标为通过。

## 5. 载荷接口的必要分界

上述惯性表示只适用于Abaqus需要承担RNA质量与惯性、且外载不重复包含这些作用的模型。若采用OpenFAST塔顶完整截面内力作为下部塔架边界载荷，需先明确截取自由体：下部塔架通常不应再次添加同一RNA的惯性与重力。最终由载荷接口审定决定两种表示的适用分析，不把一个RNA等效副本无条件用于所有载荷路径。

本步建议用户审定的唯一下一步：**建立独立RNA等效验证小样并核对其实际质量矩阵**。这是数值表达核验，后续柔性/旋转/运行适用性仍单独评价。
