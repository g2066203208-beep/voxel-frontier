## 1. 可用于统一的目标及其边界

由真实R2 ElastoDyn/Blade输入和固定官方源码，可以独立算出**零挠曲、明确姿态、内部相对运动锁定的原生软件质量算子**。本轮结果为：

- RNA质量 **676753.2907231401 kg**；实际存档ED.sum打印 **676753.250 kg**。两者差 **0.0407231401 kg，即6.0174×10⁻⁸相对差**。前者是双精度读卡重建值，后者是既有求解器输出，不混写成一个“精确到末位”的数。
- 以真实塔顶为原点、用OpenFAST对外IEC xyz坐标，RNA质心 **(−0.872962498892,约0,2.783588030306) m**。
- 质心惯量、塔顶惯量和完整6×6动能算子已写入JSON/CSV。它们足以形成“使Abaqus刚体表示与R2原生冻结算子对齐”的可审阅输入方案。
- 这不是完整物理RNA真值，也不是9.6 rpm实际运行状态的线性化矩阵。机舱/轮毂若干横向本征惯量是源码省略的模型项；本轮没有把未知实物属性补成已知。

历史 `.lin` 尚未绑定不妨碍以上明确可计算的部分；但不能把历史different-file质量676753.237515 kg、CG或M6直接贴到当前R2名下。

## 5. 当前可复算的冻结算子

原点为未变形物理塔顶O=(0,0,158)m；这里向量均是相对O的IEC xyz分量。

```text
H = (−7.072982356451393, 0, 3.368805773508373) m
U = ( 2.687,             0, 2.45) m
G = (−0.872962498891540, 0, 2.783588030306047) m

J_G (kg·m²) =
[155901495.338512,          0,        −5231495.690282]
[        0,        94926999.798112,           0     ]
[ −5231495.690282,          0,        99481015.620165]

J_O (kg·m²) =
[161145225.037954,          0,        −3587006.875091]
[        0,       100686458.495480,           0     ]
[ −3587006.875091,          0,        99996744.618091]
```

显示时将数值消减形成的近零项置为0；JSON保留原浮点值。J采用负积惯量张量约定。完整M6按 `[v_x,v_y,v_z,ω_x,ω_y,ω_z]` 顺序，由 `[mI,−mS(G);mS(G),J_O]` 组成，见 `openfast-rna-frozen-M6.csv`；三个块分别有kg、kg·m、kg·m²单位，不给混合量整体做没有尺度定义的相对误差。

从逐个质量点速度 `v+ω×r` 与机舱/轮毂/发电机方向惯量独立算动能，和M6二次型相对差 **2.32557×10⁻¹⁶**。该验证检查矩阵组装、耦合符号和参考点关系，不验证物理RNA、运行陀螺项或整机风振结果。

坐标方法审查另以三叶120°对称性的闭式二阶矩公式、单叶质量及根部一/二阶矩独立重建CG/J；没有再次沿用本脚本逐节点三维求和。CG一致，JG最大绝对差 **5.96×10⁻⁸ kg·m²**，详见 `coordinate-method-evidence.json` 的 `R2_independent_symmetric_blade_crosscheck`。该独立检查也未发现预锥符号、初始方位或GenIner处理错误。

若采用坐标附件的零偏航条件映射 `R=[[0,1,0],[0,0,1],[1,0,0]]`，目标CG绝对Abaqus坐标为 **(约0,160.783588030306,−0.872962498892)m**。完整惯量应作 `R J_G Rᵀ`，不能只排列对角元。此时建议输入六元组按Abaqus `I11,I22,I33,I12,I13,I23` 顺序约为：

`94926999.798112, 99481015.620165, 155901495.338512, 0, 0, −5231495.690282`。

该映射是已说明几何语义下的本步对齐约定；未由历史运行接口脚本证明，不冒充既有生产风载通道映射。
