# 第二章钢筋与预应力规范计算稿

## 纵筋逐段几何计算

源CAE单筋面积 A_b = 0.000490873852 m2 = 490.873852 mm2。等面积直径 d_eq = sqrt(4 A_b / pi) = 25.000 mm。何文未直接公布该直径，故称源CAE继承面积。

第i段内外排各n_i根，塔段顶部外径D_i、壁厚t_i时：

As_i = 2 n_i A_b

Ac_i = pi / 4 * [D_i^2 - (D_i - 2t_i)^2]

rho_l,i = 100 As_i / Ac_i (%)

31段计算详见同目录CSV。何文表3-2合计5440，源CAE31组RBLONG合计5440个T3D2，逐段差值均为0。该数量是分段单元数，不能自动称5440根跨接缝通长钢筋。

## 箍筋和拉筋候选几何

当前候选环向筋直径14 mm、轴向间距80 mm、内外双层。单根面积 A_h = pi*14^2/4 = 153.938 mm2。每米塔高单层面积 A_h,1 = A_h*1000/80 = 1924.226 mm2/m；双层合计3848.451 mm2/m。

以500 mm壁厚为例，每层相对1000 mm*500 mm壁截面的几何比率为1924.226/500000 = 0.384845%；双层合计0.769690%。计算表必须说明按单层还是双层比较，不能把旧台账的0.384845%误称双层总率。

拉筋候选直径6 mm，面积 A_t = pi*6^2/4 = 28.274 mm2。约480 mm竖向和不大于500 mm周向间距属于T046几何方案，不是何文公开数据。未确认构件类别、锚固形式和适用规范条款前，不作最终合格判定。

## 预应力筋名义输入

当前CAE有36个PT T3D2位置，每位置名义截面140 mm2，输入初应力1280 MPa。单位置名义力 P_1 = 140*1280 = 179200 N = 179.2 kN；36位置名义合力 P_36 = 36*179.2 = 6451.2 kN = 6.4512 MN。

若一个位置实际表示m股，则总面积 A_p,total = 36*m*140 mm2，名义总力 P_0 = 6.4512*m MN。m未由何文公开，不能将m=1的CAE表示等同真实钢束总力。有效应力 sigma_pe = 1280 MPa - 各项预应力损失。锚固、摩阻、收缩徐变、松弛及实际有效力缺少必需输入，保持HOLD。
