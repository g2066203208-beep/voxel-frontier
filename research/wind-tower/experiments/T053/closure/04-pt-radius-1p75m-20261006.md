# 04 — PT布置半径 r=1.75 m 来源与几何闭合

日期：2026-10-06  
对象：T053 `PT_36x15p2`

## 1. 源模型几何事实

对以下三代Abaqus输入中 `PT_36x15p2` 的72个端点逐点计算：

`r = sqrt(x^2 + z^2)`

结果一致：

- T026 `DTU158_RECONSTRUCTED_G1.inp`：r = 1.74999994–1.75000002 m；
- V28 `DTU158_V28_RNA_DISTRIBUTED_CHECK.inp`：r = 1.74999994–1.75000002 m；
- T053 `BASE001_T053_HE_ALIGNED_S345_CAGE_RNA_R2.inp`：r = 1.74999994–1.75000002 m。

72个节点由36条竖向T3D2的上下端点组成，y=0–112 m；因此1.75 m不是T050/T053阶段临时加入的数字，而是源Abaqus几何链连续存在的固定半径。

## 2. 公开文献边界

何泽瑜2024公开论文能够证明：
- 15.2 mm钢绞线；
- 多路PT沿圆周布置；
- PT底端固定；
- PT顶部固定在钢—混转换钢法兰。

但公开正文/表格未给PT圆周布置半径。

徐军、王丹、何泽瑜等2026同研究谱系论文能够补强36根、140 mm²等参数，但当前检索到的公开文本同样未给1.75 m布置半径。

因此1.75 m来源等级是：

**PASS-SOURCE-MODEL / PROTOTYPE-DIRECT-NOT-PUBLISHED**

它不是“何泽瑜论文直接给值”，也不是“本文经验假设”。

## 3. 几何可行性

T053第31段混凝土塔顶部（y=112 m全局，对应CSEG_31局部y=2.8 m）真实节点半径：

- 外半径 = 2.485 m；
- 内半径 = 1.985 m；
- 壁厚 = 0.500 m。

PT半径：

- r_PT = 1.750 m。

因此最不利塔顶截面PT相对混凝土内壁的径向净余量：

- 1.985 - 1.750 = **0.235 m = 235 mm**。

从下至上混凝土内半径总体更大，因此112 m顶部为当前PT与内壁距离的控制位置之一。当前PT没有穿入混凝土壁，也不存在贴内壁的几何错误。

## 4. 模型决策

T053正式生产基线：
- **继续保留 r = 1.75 m**；
- 不为了追求“文献表中一个数字”而擅自修改源模型几何；
- 论文统一称“源Abaqus模型PT布置半径1.75 m”；
- 禁止写“何泽瑜2024明确给出1.75 m”。

局部半径敏感性只承担稳健性验证，不承担反向选择设计值；最终仍需在Abaqus求解器中比较对PT轴力、Gravity平衡、低阶模态和关键截面应力的影响。

## 5. 状态

**PASS-SOURCE-MODEL / PROTOTYPE-DIRECT-NOT-PUBLISHED + PENDING-SENSITIVITY**

主基线来源问题已关闭；敏感性属于后续求解门禁。
