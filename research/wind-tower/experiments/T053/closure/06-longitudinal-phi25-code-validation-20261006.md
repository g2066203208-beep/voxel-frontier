# 06 — 纵筋490.874 mm²：从“来源HOLD”转为“规范独立验证的重建截面”

日期：2026-10-06

## 结论

何泽瑜2024表3-2只直接给31节内/外排纵筋数量，不给纵筋直径/面积。因此不能写“何泽瑜给出φ25”。

当前Abaqus截面面积：
- A = 490.874 mm²；
- 等面积圆直径 = 25.0000 mm。

本次不再用旧INP证明正确性，而使用何2024表3-2真实几何/根数 + GB 50135—2019 6.5.5、6.5.6做独立构造验算。

GB 50135—2019：
- 纵筋外排最小配筋率0.25%；
- 内排最小配筋率0.20%；
- 纵筋最小直径12 mm；
- 外排最大间距250 mm；
- 内排最大间距300 mm。

对31节逐节验算结果（完整数值见 `06-longitudinal-phi25-code-validation.csv`）：
- 最小单排配筋率 = 0.5313%；
- 最大外排弧向中心距 = 242.66 mm；
- 最大内排弧向中心距 = 232.02 mm；
- φ25 > 12 mm；
- 31/31节外排配筋率PASS；
- 31/31节内排配筋率PASS；
- 31/31节外排间距PASS；
- 31/31节内排间距PASS。

## 身份

这项不能升级为“原型直接值”，但已经可以从纯HOLD升级为：

**PASS-CODE-VALIDATED-RECONSTRUCTION / NOT-HE-DIRECT**

意思是：
- φ25/490.874 mm²不是被证明为原型施工图值；
- 但作为本文重建截面，它通过了独立规范约束，并与何2024给定根数/位置体系相容；
- 后续只需在最终Abaqus求解中检查质量、刚度和响应敏感性，不再把“有没有依据”作为未解来源问题。
