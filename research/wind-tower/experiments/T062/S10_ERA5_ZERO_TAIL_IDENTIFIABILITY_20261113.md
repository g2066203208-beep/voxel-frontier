# S10｜ERA5零观测高风尾部的可识别性边界（2026-11-13）

## 科学问题与数据身份

真实归档的嘉鱼2005–2025轮毂高度ERA5 1 m/s分箱（SOURCE: `S10_ERA5_2005_2025_HUB_1MS_BINS_20261031.csv`, SHA256 `e4058620a36b23bb218103875d4dc5b0711fc45d418b23a2208c2fc9c16c9102`）总计184080小时；其中4≤U<25 m/s有106900小时，20≤U<25 m/s的五个分箱均为**零小时**。这是观察样本内的零频数，不是物理上不存在该风速，更不能将其DLC极端工况概率设置为严格零。

## 统计上界与不同抽样单元

对独立同分布Bernoulli抽样的零事件，单侧95% Clopper–Pearson精确上界为
`p_U=1-0.05^(1/n)`。若**错误地把全部184080个连续小时视为独立**，则p_U=1.62739455525×10^-5/小时，相当于8760小时的期望次数上界0.1425597630次/年。这个数值**仅作为天真独立小时假设的敏感性对照，不是可采信的现场置信上界**；风速持续性、季节性、ERA5模型偏差和非平稳性均破坏独立性。

另一端，若以21个日历年为独立同分布的年度块、事件定义为“该年是否出现至少一个U≥20 m/s小时”，21年全部为零时，年度至少一次事件概率的单侧95%上界为`1-0.05^(1/21)=0.1329459110`，即13.2946%。这一计算不要求年内小时独立，但**仍要求年际块可交换/独立、测量机制一致**；原始逐年记录及再分析误差尚未独立核验，故只作条件性上界。年度概率与小时超越概率的估计对象不同，不能互换或据此推导50年重现期。

## 物理与设计结论

1. 观测概率的点估计为零，不意味着尾部概率的上界为零；使用零概率直接删去20–25 m/s载荷工况会使疲劳和极端响应研究出现结构性盲区。
2. 已有自适应风速试点将20–25 m/s列为条件性尾部研究，不能仅凭这份零频数断言必须或不必运行；其DLC适用性须结合授权IEC条款、风机运行范围、控制器与独立风况来源。
3. 本分析**没有**新增OpenFAST/TurbSim物理RUN、没有材料点应力、没有Miner寿命，也没有估计真实50年极值风速。既有18 NTM、36组screening及ERA5成果全部继承，不作废。

## 可复算算术（Python 3标准库）

```python
from math import exp, log
def zero_event_upper(n, alpha=0.05):
    assert isinstance(n,int) and n>0 and 0<alpha<1
    return -__import__('math').expm1(log(alpha)/n)
assert abs(zero_event_upper(184080)-1.627394555248074e-5)<1e-12
assert abs(zero_event_upper(21)-0.13294591102652342)<1e-12
print(zero_event_upper(184080),zero_event_upper(21))
```
