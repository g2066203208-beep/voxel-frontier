# T078 — 158 m混塔任务1：预应力设计闭合（CODE-DESIGN）

**状态：TASK1-CLOSED-CODE-DESIGN / PT损失与有效预应力已闭合。**

本任务只冻结本文规范设计支路的预应力数量、损失和有效预应力；不把BF=8写成何泽瑜论文原值。最终裂缝等级、疲劳、36×31全包络和最终接缝ULS按既定四任务流程放在任务3/4。

## 1. 来源身份与冻结边界

- 何泽瑜2024直接：15.2 mm钢绞线、T3D2表示、底端固定、顶部锚固于钢—混转换法兰。
- Xu/He同谱系2025：体外无黏结、Ep=195 GPa、初始预应力1280 MPa、fpy=1320 MPa、fpk=1860 MPa。
- 当前模型重建：36个环向PT位置、r=1.75 m、单股面积140 mm²。以上36位置/r不是何文公开直接值。
- 本任务设计值：每位置8股，即36×8=288股；Ap=40320 mm²。身份为CODE-DESIGN。

## 2. 规范原文位置

NB/T 10907—2021附录A明确要求考虑五类损失：孔道/导向摩擦、锚具变形与回缩及接缝压密、混凝土弹性压缩、钢绞线松弛、混凝土收缩徐变。具体采用A.1.2～A.1.6。

- A.1.2：sigma_l1 = sigma_con*[1-exp(-(k*x+mu*theta))]。体外筋表A.1.2给出k=0；摩擦只在转向装置和锚固装置管道段发生。
- A.1.3：sigma_l2 = Ep*Delta_l/l。表A.1.3夹片锚具无顶压取6 mm；接缝压密按每个接缝计。
- A.1.4：一次张拉后张构件弹性压缩损失为0；分批张拉采用(m-1)/(2m)*np*sigma_c。
- A.1.5：1280/1860=0.6882<=0.7，故alpha=0.125、gamma=0.5。
- A.1.6：后张法收缩徐变损失采用[55+300*sigma_pc/fcu_transfer]/(1+15*rho)。

## 3. 本文登记的保守设计假设

原型资料没有给张拉施工方案、锚具型号、接缝压密量和张拉龄期强度。为避免伪造原型参数，本任务把这些明确登记为本文设计假设：

1. 当前重建PT为直线体外无黏结筋，无转向点：k=0、theta=0，因此自由长度摩阻损失取0。
2. 单端张拉，活动端按夹片锚具无顶压的6 mm回缩。
3. 31个混凝土节段之间按30个水平接缝计；由于真实接缝型式未公开，采用表A.1.3列值中的上界2 mm/缝作为设计上界。
4. 36个环向束位置按36批顺序张拉，m=36；这是比一次整体张拉更不利的弹性压缩支路。
5. 收缩徐变上界取rho=0，使分母最小；张拉龄期强度未公开，主设计支路登记为0.75×混凝土等级，并另给名义强度敏感性。

## 4. BF=8逐项损失计算

总股数=36×8=288；Ap=288×140=40320 mm²。  
名义初始力P0=Ap×1280=51.6096 MN。

1. 摩阻损失：k=0、theta=0，因此 sigma_l1=0.000 MPa。
2. 锚具+接缝压密：Delta_l=6+30×2=66.0 mm；sigma_l2=195000×66/112000=114.911 MPa。
3. 弹性压缩：36批张拉、按31段Ec/A沿112 m长度加权，sigma_l3=22.555 MPa。
4. 松弛：0.125×(1280/1860-0.5)×1280=30.108 MPa。
5. 收缩徐变：rho=0、0.75×等级支路逐段计算，最不利CSEG_27，sigma_l5=126.475 MPa。

**总损失=294.049 MPa，占初始应力22.97%。**  
**有效预应力 sigma_pe=985.951 MPa，eta=0.7703。**  
**有效总预应力 Pe=39.754 MN。**

## 5. 为什么采用BF=8

T072既有接缝/预压工程敏感性在更不利的eta=0.70下反算等效最小BF约5.59，其最小整数为BF=6。该结果不是规范直接给出的股数，因此本任务不把BF6称为“规范规定最小股数”。

为给接缝、施工和损失未确定性留出设计余量，CODE-DESIGN支路采用BF=8；相对5.59的面积/股数裕量约43.1%。

采用附录A保守损失后eta=0.7703，仍高于T077已扫描的0.70下界。T077已经对BF8扫描eta=0.70/0.80/0.85/0.90/1.00，并对4个31段控制工况完成纵筋ULS，因此本任务的有效预应力处在已有容量分析域内。

## 6. 31段永久状态压紧检查

使用T074纯重力基线与本任务有效Pe做毛截面边缘应力检查：

sigma_min = (N_G + Pe)/A - M_G*(D/2)/I

这个检查回答“重力+有效预应力下是否保持全截面受压”，不把它冒充运行ETM裂缝验算。

**31/31段均PASS；最小压应力由CSEG_31控制，sigma_min=6.333 MPa > 0。**
