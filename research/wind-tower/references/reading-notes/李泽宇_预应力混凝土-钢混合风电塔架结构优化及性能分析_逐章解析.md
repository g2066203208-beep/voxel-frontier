# 1. 第1章绪论：作者为什么要研究PCSH混塔

## 1.1 风机大型化带来的塔架问题

风机大型化意味着叶轮直径和轮毂高度不断增加。传统锥形钢塔若继续增高，需要更大的直径和壁厚，造成：

- 钢材消耗和成本增加；
- 薄壁钢壳局部屈曲风险提高；
- 塔架柔度增加，自振频率更容易接近1P/3P激励区；
- 大直径钢筒的公路、桥梁和山地运输受限；
- 高塔方案的整体经济性下降。

因此作者研究下部采用预应力混凝土、上部采用钢塔的PCSH体系。

PCSH = Prestressed Concrete-Steel Hybrid。

基本思想是：

- 下部弯矩大、刚度需求高：采用混凝土；
- 上部要求轻、安装方便：采用钢结构；
- 通过预应力改善混凝土受拉区开裂和疲劳性能。

## 1.2 为什么必须施加预应力

塔架受风时近似悬臂受弯。一个截面一侧受压、另一侧受拉。

混凝土抗压能力强，但抗拉和抗裂能力弱。因此预先施加压应力，使服役荷载产生的拉应力被部分或全部抵消。

概念上可写为：

[
sigma_{mathrm{service}}
=
sigma_{mathrm{wind}}
+
sigma_{mathrm{prestress}}
]

其中预应力产生的初始压应力有利于：

- 抑制开裂；
- 保持截面刚度；
- 改善正常使用性能；
- 改善长期循环荷载下的疲劳表现。

## 1.3 核心设计矛盾

PCSH不是“混凝土越多越好”。

混凝土段增加：

- 刚度提高；
- 钢材可减少；
- 但自重、施工量、预应力和基础作用增加。

钢塔段增加：

- 自重较小；
- 工业化程度高；
- 但钢材费用和局部屈曲问题更突出。

因此必须同时优化：

- 钢段高度；
- 混凝土段高度；
- 各段直径；
- 壁厚；
- 预应力筋用量；
- 结构频率、位移、强度、稳定、疲劳和经济性。

# 2. 陆上2 MW PCSH混塔优化

## 2.1 研究对象

论文第一项核心研究针对2 MW陆上风机。

关键基准参数：

- 塔架总高度：77.5 m；
- 转子直径：93.4 m；
- 机舱+轮毂质量：80 t；
- 叶片总质量：48.5 t；
- 额定转速：23 rpm；
- 额定风速：11 m/s；
- 切入风速：3 m/s；
- 切出风速：25 m/s；
- 极端风速：52.5 m/s；
- IEC风区：IIIA；
- 年平均风速：7.5 m/s；
- 最大湍流强度：0.18。

注意：这些是李泽宇2 MW研究对象的参数，不能直接替换为当前10 MW / 158 m混塔的参数。

## 2.2 优化前后主要结构尺寸

论文给出的优化结果中，塔架总高度保持77.5 m，但钢—混分配发生显著变化。

| 参数 | 优化前 | 优化后 |
|---|---:|---:|
| 总塔高 | 77.5 m | 77.5 m |
| 钢塔段数量 | 3 | 1 |
| 钢塔总高度 | 61.5 m | 22.0 m |
| 混凝土段高度 | 16.0 m | 55.5 m |
| 钢段顶径 | 2.686 m | 2.686 m |
| 钢段底径 | 约4.400 m | 约3.296 m |
| 混凝土顶径 | 约4.878 m | 约3.549 m |
| 混凝土底径 | 6.900 m | 5.800 m |
| 混凝土顶壁厚 | 500 mm | 270 mm |
| 混凝土底壁厚 | 500 mm | 285 mm |
| 预应力孔道数 | 36 | 36 |
| 预应力筋总面积 | 40,320 mm² | 24,872 mm² |

最终钢段高度约占总塔高30%。

关键认识：

> 优化不是简单“所有尺寸都减小”。优化后混凝土段显著增高，但混凝土壁厚显著减小，钢塔长度和用钢量明显下降。其本质是重新分配材料，使高刚度、低成本材料放在更有效的位置。

## 2.3 设计变量

可以把一种候选塔架写成设计变量向量：

[
mathbf{x}=[x_1,x_2,ldots,x_n]^T
]

典型变量包括：

### 钢塔
- 各钢段高度 (H_s^j)；
- 各钢段壁厚 (t_s^j)；
- 钢段顶部/底部直径 (D_{st}^j,D_{sb}^j)。

### 混凝土塔
- 混凝土段高度 (H_c)；
- 顶部/底部壁厚 (t_{ct},t_{cb})；
- 顶部/底部直径 (D_{ct},D_{cb})。

### 预应力系统
- 预应力筋总面积 (A_p) 等。

论文设置有限搜索边界，而不是让算法无限制改变尺寸。例如钢壁厚、混凝土壁厚、混凝土段高度、预应力筋面积等均有工程合理范围。

## 2.4 目标函数不是“重量最小”，而是LCOE

LCOE = Levelized Cost of Energy，平准化度电成本。

概念上：

[
LCOE
=
frac{	ext{全寿命周期总成本}}
{	ext{全寿命周期发电量}}
]

因此优化目标并非单纯减少塔架质量。

这解释了为什么最终塔架总重量增加仍然可能是经济最优方案。

优化前后重量大致为：

- 原钢段约90 t；
- 原混凝土约338 t；
- 原塔总重约428 t；

优化后：

- 钢约16 t；
- 混凝土约528 t；
- 总塔重约544 t。

因此：

- 钢材用量大幅下降；
- 混凝土用量增加；
- 总重量反而增加；
- 但昂贵钢材和全寿命周期成本下降，LCOE降低。

这说明结构优化不能等同于“轻量化”。

## 2.5 优化约束

问题可写为：

[
min f(mathbf{x})
]

同时满足：

[
h_i(mathbf{x})le0
]

论文考虑的约束包括：

### 钢塔
- 局部屈曲；
- 整体稳定；
- 轴压；
- 抗剪；
- 抗扭；
- 组合承载力；
- 疲劳。

### 混凝土塔
- 承载能力；
- 疲劳；
- 预应力系统安全及疲劳。

### 整机/整体
- 一阶自振频率；
- 塔顶位移等。

因此最优解实际是“所有约束都满足的前提下经济指标最好”。

## 2.6 罚函数思想

如果一个尺寸组合成本很低，但违反安全约束，就不能成为最优解。

可概念化为：

[
F(mathbf{x})
=
LCOE(mathbf{x})
+
Penalty(mathbf{x})
]

满足约束时：

[
Penalty=0
]

违反约束时：

[
Penaltygg0
]

这样优化算法会自动淘汰不满足规范或性能要求的候选方案。

# 3. 材料利用率：怎么看“优化以后是不是更合理”

论文使用材料利用率/约束利用率判断设计是否充分。

可简单表示为：

[
R=
frac{	ext{结构实际需求}}
{	ext{允许承载能力}}
]

- (Rll1)：材料富余大；
- (Rrightarrow1^{-})：材料利用比较充分；
- (R>1)：约束不满足。

部分典型优化变化：

- 钢塔局部屈曲利用率：约0.45 → 0.84；
- 钢塔承压：约0.53 → 0.76；
- 钢塔组合承载：约0.29 → 0.67；
- 混凝土迎风侧疲劳：约0.56 → 0.94；
- 预应力筋疲劳：约0.93 → 0.91；
- 抗扭约束利用率很低，对设计不是主要控制项。

由此可以看出：

> 最终方案的关键控制因素并非所有约束平均起作用，而主要是钢塔局部屈曲、混凝土疲劳及预应力体系疲劳等接近边界的约束。

这说明风机塔设计不能只看静力强度，长期循环荷载可能成为关键控制问题。

# 5. PUPSO到底是什么

## 5.1 普通PSO

PSO = Particle Swarm Optimization，粒子群优化。

每个粒子代表一组塔架设计变量。

典型更新公式：

[
v_i^{k+1}
=
wv_i^k
+c_1r_1(pbest_i-x_i^k)
+c_2r_2(gbest-x_i^k)
]

[
x_i^{k+1}
=
x_i^k+v_i^{k+1}
]

三个作用：

1. 惯性：保留原搜索方向；
2. 个体经验：靠近自身历史最优解；
3. 群体经验：靠近全局当前最优解。

## 5.2 UPSO改进

普通PSO可能过早聚集在局部最优。

论文通过动态调整惯性权重和学习因子，并引入随机扰动提高跳出局部最优的能力。

文中使用的动态权重形式为：

[
w=w_{min}+(w_{max}-w_{min})e^{-20(m/M)^6}
]

并进一步构造随迭代变化的 (c_1,c_2)。

其工程含义是：

- 搜索早期提高全局探索；
- 搜索后期逐渐增强局部收敛；
- 粒子群过度集中时增加随机扰动。

## 5.3 PUPSO的“P”

PUPSO = Parallel Updated Particle Swarm Optimization。

关键改进是将不同粒子的结构性能与目标函数计算并行执行。

每个粒子都是一组独立塔架设计，因此可以并行求：

- 强度；
- 稳定；
- 位移；
- 频率；
- 疲劳；
- LCOE。

最终再将fitness汇总给优化器更新粒子。

论文报告的完整计算时间量级：

- PSO：约432759 s；
- UPSO：约451480 s；
- PUPSO：约212801 s。

即PUPSO显著缩短总体优化时间。

# 6. LCOE优化结果

论文在不同年等效利用小时情形下比较LCOE。

典型结果：

- 0.3613 → 0.3474 元/kWh；
- 0.3874 → 0.3722 元/kWh；
- 0.3993 → 0.3835 元/kWh；
- 0.4769 → 0.4571 元/kWh。

说明优化结果并非只改善结构性能，也降低了全寿命周期度电成本。

# 7. 这一阶段用了什么结构模型：必须避免误读

非常重要：PUPSO优化阶段并不是整塔全实体非线性Abaqus精细模型。

为了承担大量优化迭代，作者对结构作了明显简化：

- PCSH塔架按变截面悬臂梁处理；
- 塔底固结；
- 叶片、轮毂、机舱等上部组件用集中质量等效；
- 沿塔分布质量作离散等效；
- 优化阶段不以完整材料非线性和局部精细接触为主；
- 门洞等局部问题并不是该优化模型的核心；
- 主要从整体结构层面对设计变量进行快速搜索。

这直接揭示博士论文后续“两尺度有限元模型”出现的原因：

> 快速模型适合优化搜索，但无法回答局部非线性、材料损伤、预应力筋—混凝土协同和关键区域应力等问题，所以必须再建立高可信度精细模型。

# 8. 目前这一部分最重要的结论

1. 李泽宇没有直接把“全实体高精度模型”用于全部优化迭代。
2. 优化目标是LCOE，不是单纯减重。
3. 优化结果允许总重量增加，只要全寿命经济性更优。
4. 混凝土段明显加长、钢塔段明显缩短，同时混凝土壁厚反而减小。
5. 钢塔局部屈曲、混凝土疲劳和预应力体系疲劳是重要控制因素。
6. 一阶频率必须与1P/3P激励带一起判断。
7. PUPSO的工程价值包含“改进搜索策略 + 将独立粒子计算并行化”。
8. 论文结构上先“快速优化”，再“精细建模和试验验证”，是一个非常重要的方法学安排。

# 9. 对当前10 MW / 158 m混塔论文的启示

## 9.1 可以直接学习的方法

### A. “优化模型”和“最终精细分析模型”分层

后续10 MW混塔第五章若开展参数优化，不应让每个候选结构都运行完整的：

- 实体混凝土；
- 普通纵筋；
- 环向钢筋；
- 构造钢筋；
- 预应力筋；
- 水平接缝；
- 钢—混过渡段；
- RNA空间模型；
- 接触和材料非线性。

合理路线应当是：

[
简化模型进行大规模参数搜索
]

然后：

[
候选最优解
rightarrow
精细Abaqus模型重建
rightarrow
重新验证
]

### B. 优化变量必须来自真实结构和规范边界

不能凭空选变量。

未来10 MW混塔可考虑的变量应从原型资料和规范约束中逐项建立，例如：

- 混凝土段高度；
- 转换段高度/位置；
- 塔筒直径；
- 壁厚；
- 纵筋配筋率；
- 环筋配筋；
- 预应力面积或预应力水平；
- 钢塔壁厚分段参数。

但每个变量的允许范围必须有原型文献、设计规范或可靠工程依据。

### C. 约束比算法本身更重要

优化不是先决定“用PSO还是遗传算法”，而是先回答：

- 哪些性能是真正的控制项？
- 各约束采用哪个规范/论文计算式？
- 如何计算疲劳、局部屈曲、位移、频率和承载能力？
- 哪一层采用简化公式，哪一层必须回到精细FE？

### D. 当前Rainflow/DEL可以成为后续疲劳优化输入的一部分

现有10 MW论文已经建立多随机种子OpenFAST载荷、Rainflow和DEL流程，这可以用于：

- 控制工况识别；
- 参数方案之间的疲劳载荷对比；
- 后续局部应力疲劳计算的工况筛选。

但DEL不能自动等价为材料疲劳寿命。若论文要进入疲劳寿命层面，仍需进一步建立：

[
局部应力时程
rightarrow
Rainflow
rightarrow
S-N
rightarrow
Miner
rightarrow
寿命
]

# 12. 两尺度有限元方法：作者为什么不能只用一种单元

这是李泽宇论文方法学上非常关键的一部分。

作者需要同时回答两类问题：

### A. 整体问题
- 塔顶位移多大；
- 整体刚度如何；
- 自振频率是多少；
- 全塔内力如何沿高度分布；
- 结构在静力、风和地震作用下整体是否安全。

### B. 局部问题
- 塔底等高应力区域是否开裂或压碎；
- 局部混凝土应力如何分布；
- 关键区失效形态是什么；
- 预应力筋附近及关键截面的材料响应如何；
- 后续疲劳分析需要的局部应力时程如何获得。

如果整塔全部采用3D实体单元并考虑混凝土非线性、钢筋和预应力筋，精度高，但自由度和非线性迭代成本很大；如果整塔全部采用梁单元，计算很快，却只能准确抓整体行为，无法可靠描述局部应力场和局部破坏形态。

因此作者的核心思想是：

**关键区精细实体化 + 其余区域纤维梁化**

即“两尺度”模型。

论文和作者对应期刊论文均明确说明：

- 感兴趣/高应力的PC塔段用实体单元；
- 其余PC塔段用3D纤维梁单元；
- 建立全实体模型、两尺度模型、全纤维梁模型三套模型进行对比；
- 通过缩尺PCSH子结构试验验证；
- 再通过循环荷载下的预应力混凝土塔子结构试验验证循环响应；
- 最后应用到优化后的足尺PCSH塔。

这不是“为了画图漂亮而混合建模”，而是为了同时获得全局精度、局部信息和计算效率。

# 13. 什么是3D纤维梁：必须真正理解

普通梁单元把整个截面等效为几个截面参数：

A, Iy, Iz, J

如果材料线弹性，截面响应可以通过轴向刚度和弯曲刚度计算。

但混凝土塔进入开裂、压缩非线性、钢筋屈服后，“整个截面用一个E”就不够。

纤维梁的思想是：

> 不把整个截面看成一个材料点，而是把截面离散成大量小纤维，每一根纤维拥有自己的位置、面积和材料本构。

对于截面上第 i 个纤维：

- 面积：Ai
- 坐标：(yi, zi)
- 应变：epsilon_i
- 应力：sigma_i

在平截面假定下，截面纤维轴向应变可概念化为：

epsilon_i = epsilon_0 - kappa_y * zi + kappa_z * yi

也就是说，同一个截面上：

- 中性轴附近纤维应变小；
- 受拉边纤维可能进入开裂/钢筋受拉；
- 受压边纤维可能进入混凝土非线性压缩。

每个纤维分别通过自己的材料本构：

sigma_i = f(epsilon_i, history)

得到应力。

然后将所有纤维积分回截面内力：

N = sum(sigma_i * Ai)

My = sum(sigma_i * Ai * zi)

Mz = sum(sigma_i * Ai * yi)

所以纤维梁比普通线弹性梁强的地方在于：

> 它仍然是“梁”，计算量远小于整塔实体模型，但截面内部已经保留了混凝土和钢筋随加载逐步进入非线性的能力。

这就是作者选择3D纤维梁作为“粗尺度区域”的根本原因。

# 14. 为什么还需要自己写UMAT

李泽宇不是简单调用一个现成梁截面就结束。

博士论文摘要明确指出：

> 为Abaqus隐式分析开发了三维纤维梁单元本构子程序UMAT。

在每个增量中，Abaqus将当前应变、应变增量、历史变量和时间信息交给用户材料程序。UMAT需要返回更新后的应力、状态变量和材料切线刚度。

对纤维梁来说，每个纤维都要根据自己的加载历史判断：

- 当前处于加载还是卸载；
- 混凝土是否进入非线性；
- 是否发生刚度退化；
- 钢筋是否屈服；
- 循环加载下是否出现滞回行为等。

作者同一研究团队此前关于RC构件两尺度模拟的工作也明确指出：Abaqus梁单元缺少其所需的单轴滞回材料模型，因此需要将相应单轴本构通过用户材料子程序用于纤维梁。

因此UMAT在这里不是“为了自动建模”，而是：

**给纤维梁提供所需的非线性材料本构。**

这点与Abaqus脚本自动化完全不同，不能混为一谈。

# 15. 两尺度区域怎么划：不是随便切一段

论文对应期刊文献明确说明：

> PCSH混凝土塔段的最大应力和损伤往往发生在塔底或其他高应力关键区，因此将选定的高应力区域用精细实体单元模拟，其余区域用梁单元模拟。

所以区域划分原则本质是：

**哪里需要局部破坏信息，哪里实体化。**

而不是：

> 下半段随便用实体、上半段随便用梁。

合理的两尺度划分需要前置判断：

1. 用整体模型先确定高应力/高损伤区；
2. 根据试验破坏位置或已有文献确定潜在塑性区/关键区；
3. 将实体区域扩展到足够长度，避免尺度接口正好穿过强非线性核心；
4. 其余远离局部破坏的区域用纤维梁承担整体刚度和内力传递。

这与普通“局部细化网格”不同：

- 局部细化：仍然是同一类单元，只改变网格尺寸；
- 两尺度：实体单元和梁单元在不同区域共同组成同一个结构模型。

# 16. 实体区和纤维梁区为什么必须正确传力

实体区和梁区的自由度描述并不一样。尺度接口必须把截面轴力、剪力、弯矩和扭矩可靠地从一种离散形式传到另一种离散形式，同时保证运动兼容。

需要传递的广义截面内力包括：

N, Vy, Vz, My, Mz, T

两尺度建模真正的难点之一，就是：

> 如何让一根“只有中心线和截面”的纤维梁，与一整圈三维实体截面之间保持正确的运动学关系和力学传递。

李泽宇论文的方法学价值在于不是只提出概念，而是将这种两尺度组合真正用于PCSH塔，并通过试验、全实体模型和全梁模型三方验证。

当前精读阶段先记住原则：

**接口必须同时守住位移兼容和截面合力/合矩传递。**

后续对照原PDF图号时，需要继续记录其具体Abaqus连接定义和接口位置。

# 17. 预应力筋为什么是两尺度模型里的另一个难点

如果整个混凝土塔都采用实体单元，预应力筋可以作为独立杆/桁架单元布置在三维空间，再通过约束、接触、嵌入或其他方式与混凝土发生作用。

但是当一部分混凝土被替换成“纤维梁中心线”后，问题出现了：

> 真实预应力筋在塔壁圆周某一半径上，而纤维梁只是一根中心轴线，二者在空间上不重合。

所以不能简单地把预应力筋节点直接合并到梁中心线上，否则会破坏真实偏心位置及其力矩效应。

博士论文摘要明确说明作者为此：

> 发展了模拟预应力筋与纤维梁单元相互作用的连接方式。

英文摘要将其描述为用于预应力钢筋与纤维梁相互作用的 elastic rigid connection / customized connection type。

其力学目的可以概括为：

- 保留预应力筋真实空间位置；
- 将预应力筋轴力正确传递到纤维梁截面；
- 使梁截面变形能带动相应位置的预应力筋；
- 避免把偏心布置的预应力筋错误地压缩到塔筒中心轴线上。

所以李泽宇的“预应力筋-纤维梁连接”不能简单等同于实体混凝土中的普通 Embedded Region。

# 18. 作者的验证不是一次，而是三级

## 第一级：PCSH缩尺子结构单调加载试验

作者首先进行了缩尺PCSH风机塔子结构静力试验。

随后建立三种数值模型：

### 模型A：全实体模型
优点：
- 能看局部应力；
- 能看损伤和破坏形态。

缺点：
- 计算成本高。

### 模型B：两尺度模型
- 高应力/感兴趣区：实体；
- 其余区域：3D纤维梁。

目标：
- 保留全实体模型的关键局部能力；
- 降低总体计算成本。

### 模型C：全纤维梁模型
优点：
- 快。

缺点：
- 主要适合整体响应；
- 不能给出实体级三维局部应力场和局部破坏形态。

三种模型共同与试验结果比较。

作者对应的 Engineering Structures 论文明确指出：

- 两尺度模型的力-位移曲线与试验结果接近；
- 两尺度模型与全实体、全纤维梁模型在整体响应上具有良好一致性；
- 两尺度模型能同时描述整体行为、局部破坏模式和局部应力分布；
- 全纤维梁模型主要适合预测整体行为，不适合直接替代实体局部分析。

# 19. 第二级：为什么还要再做循环荷载验证

单调推到破坏，只能证明模型在单向加载下基本正确。

但是风机和地震都具有明显循环特征：

正向加载 -> 卸载 -> 反向加载 -> 再卸载 -> 再正向加载

材料可能经历：

- 加载；
- 卸载；
- 反向加载；
- 刚度退化；
- 残余变形；
- 滞回耗能。

所以博士论文没有在单调试验后停止，而是进一步建立：

- 循环试验对应的全实体模型；
- 两尺度模型；
- 全梁模型；

用于验证预应力混凝土风电塔在循环荷载下的准确性和可靠性。

这一层验证尤其重要，因为后面作者还要进行：

- 地震非线性时程；
- 风致循环响应；
- 疲劳分析。

如果材料子程序只在单调加载下正确，而卸载和反向加载不可信，那么后续循环动力分析就没有可靠基础。

# 20. 第三级：从缩尺试验升级到足尺优化塔

只有缩尺模型验证仍然不够。

作者最后将已经验证的两尺度方法用于前面PUPSO优化后的足尺2 MW PCSH塔架。

对应期刊文献公开信息表明，足尺模型中：

- 塔底固定；
- 上部风机系统按具有质量的刚体/等效系统处理；
- 混凝土塔沿高度采用变截面离散；
- 文献报道梁尺度离散长度约为2 m量级；
- 预应力损失纳入锚固、摩擦、应力松弛、混凝土徐变和收缩等影响；
- 两尺度模型用于静力、模态及疲劳等分析。

作者继续把两尺度模型与全实体模型、全纤维梁模型进行比较。

最终得到的结论不是“梁模型没用”，而是：

> 全纤维梁模型适合全局响应；全实体模型局部能力强但成本高；两尺度模型在两者之间取得精度和效率平衡。

# 21. 为什么说这一章比“频率对上了”更高级

常见有限元验证容易形成：

建立模型 -> 计算频率 -> 与参考值相差很小 -> 宣布模型正确

但频率吻合主要说明：

> 整体质量和刚度大致合理。

它不能单独证明：

- 混凝土非线性正确；
- 局部应力正确；
- 破坏位置正确；
- 循环滞回正确；
- 预应力与混凝土相互作用正确。

李泽宇采用的是更完整的验证链：

材料本构/纤维梁
-> 缩尺PCSH子结构单调试验
-> 全实体 vs 两尺度 vs 全梁
-> 循环荷载再验证
-> 足尺PCSH模型

这才真正证明模型既能算整体，又能在关键区算局部，而且计算效率具有工程意义。

# 22. 三种模型分别能回答什么

| 模型 | 整体位移/刚度 | 模态 | 局部应力 | 局部损伤/破坏 | 计算成本 |
|---|---|---|---|---|---|
| 全实体模型 | 强 | 强 | 强 | 强 | 最高 |
| 两尺度模型 | 强 | 强 | 关键区强 | 关键区强 | 中等 |
| 全纤维梁模型 | 强 | 强 | 可得截面纤维响应，但不是3D局部场 | 弱，不适合实体级局部破坏 | 最低 |

必须特别区分：

纤维梁虽然能得到各纤维的应力、应变和截面非线性，但它不能等价于三维实体局部应力场。

例如：

- 孔洞边缘应力集中；
- 锚具局部承压；
- 钢-混过渡段复杂三维传力；
- 局部接触；
- 局部开裂路径；

这些仍然需要实体/壳等高维模型。

# 23. 对当前10 MW / 158 m Abaqus混塔最重要的启示

## 23.1 当前精细模型属于李泽宇路线里的“精细层”

目前10 MW混塔正在核查：

- 混凝土实体；
- 纵筋；
- 环筋；
- 构造拉筋；
- 预应力筋；
- 水平接缝；
- 钢-混转换结构；
- RNA等效；
- 边界和预应力初始状态。

这些内容本质上对应：

**局部/最终验证模型**

而不是几千个优化方案都重复运行的快速模型。

## 23.2 可以借鉴“两层模型体系”

未来比较合理的结构是：

### Level 1：快速全局模型
用于：
- 参数敏感性；
- 大量方案筛选；
- 优化搜索；
- 控制工况快速比较。

### Level 2：精细Abaqus模型
用于：
- 候选最优方案复核；
- 局部应力；
- 混凝土损伤；
- 配筋和预应力响应；
- 转换段和接缝关键区域；
- 最终论文图表。

这样可以避免“为了做一次优化而跑几千个超大型实体模型”的计算灾难。

## 23.3 但不能机械照搬李泽宇的纤维梁

是否真的要在当前论文中重新开发UMAT，需要单独评估。

原因：

1. 李泽宇的UMAT本身就是博士论文方法创新之一；
2. 当前硕士论文主线不是“开发新纤维梁本构”；
3. 自己重新写一个未经充分验证的UMAT，反而增加可信度风险；
4. 当前已有OpenFAST承担整机气动弹性与载荷计算，Abaqus承担混塔精细结构分析，任务分工与李泽宇并不完全相同。

因此当前论文更应该学习的是：

**多层级模型 + 逐级验证**

而不是为了模仿而复制：

**自研UMAT。**

# 24. 这一章读完必须记住的10句话

1. 两尺度不是“两种网格尺寸”，而是两种不同建模尺度/单元体系组合。
2. 纤维梁通过截面纤维积分保留材料非线性，比普通等效梁更强。
3. UMAT负责材料应力更新和切线刚度，不是自动建模脚本。
4. 高应力、可能破坏且需要局部场信息的位置才值得实体化。
5. 实体-梁接口必须满足运动兼容和截面合力/合矩传递。
6. 预应力筋与纤维梁中心线不共线，因此需要专门连接方式保持空间位置和传力。
7. 单调试验验证还不够，作者又用循环荷载模型验证反向加载可靠性。
8. 全实体模型最详细但最慢；全纤维梁最快但局部能力不足。
9. 两尺度模型的目标是“整体与局部兼顾，同时降低计算成本”。
10. 对当前10 MW论文最应该学的是分层建模和验证闭环，不是为了模仿而重新开发UMAT。

# 27. 第5章：陆上PCSH塔架地震易损性分析——逐页精读

> 本节依据博士论文第5章正文逐页核对。章节起始于PDF文件页110（论文印刷页98）。这里的地震部分不是当前10 MW论文的主线，但它是理解李泽宇“经验证的两尺度模型如何进入性能分析”的最佳案例。

## 27.1 第5章真正要回答什么

第4章解决的是：

> 两尺度模型能不能既保持关键局部精度，又显著降低计算量？

第5章则把这个已经验证的模型放进强地震环境，回答四个问题：

1. PCSH塔架在不同地震强度下如何从弹性进入损伤乃至倒塌？
2. 什么参数适合作为地震强度指标 IM，什么结构响应适合作为工程需求参数 EDP？
3. 近场/远场、不同场地类别会怎样改变失效概率？
4. IDA 与 MSA 两种易损性方法结果差多少、代价差多少？

因此第5章不是“多跑几条地震波”，而是：

**非线性时程 → 极限状态定义 → 地震动统计 → IDA/MSA → 易损性曲线 → 破坏模式与设计建议。**

## 27.2 地震分析模型：在第4章两尺度模型上又做了什么修改

博士论文PDF p110–111（印刷p98–99）明确说明，第5章没有原封不动照搬第4章模型。

为了捕捉**钢塔段局部失稳/屈曲**，作者将钢塔受力较大的下部区域由梁单元升级为壳单元，其余钢塔仍用梁单元；预应力混凝土段继续采用第4章的两尺度方法。

同时加入了门洞影响：

- 门洞高度位置：约 **1.2 m**；
- 为降低门洞应力集中，在门洞处设置 **80 mm厚 Q345E钢板**；
- 地震设防烈度：**7度**；
- 场地类别：**Ⅲ类场地**；
- 阻尼比：**3%**；
- 阻尼形式：**Rayleigh阻尼**；
- 未建立底部混凝土基础，而将塔底简化为**刚性环形边界**；
- 通过塔底输入加速度时程施加地震作用。

第5章模型总单元数为 **30,241**：

| 单元 | 数量 | 用途 |
|---|---:|---|
| C3D8R | 26,547 | 关键预应力混凝土实体区域 |
| T3D2 | 2,906 | 钢筋/预应力筋等桁架构件 |
| B31 | 68 | 梁尺度区域 |
| S4R | 720 | 钢塔下部局部壳区域 |

这一步非常重要：作者发现“真正可能控制倒塌的是钢段底部屈曲”，因此把模型分辨率放到了这个物理问题上，而不是所有地方一视同仁地加密。

## 27.4 为什么顶部转角不能当作地震安全判据

在工况1–3中：

- 顶部水平位移小于塔高的1.25%；
- 顶部转角小于5°；
- 结构仍有足够承载能力。

当PGA提高到约0.7g时：

- 塔顶出现较大且不可恢复的水平位移；
- 结构产生显著塑性变形；
- 可以判断已经发生破坏。

但此时一个反直觉结果出现了：

> 即便塔架已经破坏，顶部转角仍可能小于5°。

所以作者明确指出：

**顶部转角更适合用于检查叶片—塔身间隙，而不适合作为塔架结构安全/倒塌的EDP。**

这就是后面为什么选“最大顶部水平位移”而不是“顶部转角”作为工程需求参数。

## 27.5 高阶模态为什么不能忽略

PDF p114（印刷p102）的顶部水平加速度功率谱分析给出，第4章模型前三阶自振频率约为：

- 一阶：0.556 Hz；
- 二阶：2.13 Hz；
- 三阶：7.62 Hz。

作者发现前三阶模态均影响地震加速度响应，其中前两阶贡献更明显。

更关键的是，沿塔高的加速度放大系数最大值出现在：

\[
z\approx55.3\,\text{m}
\]

这正好接近：

- 钢塔段—预应力混凝土段连接位置；
- 总塔高约2/3；
- 二阶弯曲振型水平位移较大的区域。

因此作者认为：

> PCSH塔属于细长柔性结构，不能只根据第一振型判断地震响应，高阶模态会显著影响局部响应。

## 27.6 易损性到底是什么

论文把地震易损性定义为：

> 在给定地震强度 \(IM\) 下，结构达到或超过某一极限状态的条件概率。

它不再只回答：

> “这个地震下塔坏没坏？”

而是回答：

> “在PGA=0.5g时，有多大概率超过LS1？多大概率超过LS2？多大概率超过LS3？”

因此结果最终是一组概率曲线。

---

## 27.7 IM为什么选PGA

论文讨论了多个可能的地震强度指标：

- PGV；
- PGA；
- 与第一周期相关的谱加速度等。

但作者没有选单一第一周期谱加速度作为主IM，理由是：

1. 前两阶模态参与明显；
2. 前三阶模态均对塔架动力响应有贡献；
3. 单一第一周期谱加速度主要突出一阶特征；
4. 抗震规范也大量使用加速度描述地震强度。

因此最终：

\[
\boxed{IM=PGA}
\]

## 27.8 EDP为什么选塔顶最大水平位移

EDP必须能够随着结构从完好、损伤直到破坏持续表征结构状态。

作者已经在前面的强震计算中看到：

- 顶部转角即使在结构破坏时也可能没有越过5°；
- 最大顶部水平位移则直接反映整体变形，并且本身就是塔架设计约束。

因此：

\[
\boxed{EDP=D_{\max}=\text{塔顶最大水平位移}}
\]

## 27.10 LS1、LS2、LS3到底如何定义

这是整章最关键的定义之一。

### LS1：开始明显离开线弹性

作者把：

> **Pushover曲线的线性极限**

定义为LS1。

对这座77.5 m塔，后续表5.6中对应的顶部位移为约：

\[
520\text{ mm}
\]

### LS2：塔顶位移达到塔高1%

根据高耸结构相关要求：

\[
D_{\max}=0.01H
\]

因此：

\[
H=77.5\text{ m}\Rightarrow D_{\max}=775\text{ mm}
\]

即LS2。

### LS3：接近倒塌/严重失效

作者同时考虑两个判据：

- 塔顶水平位移达到 \(1.25\%H\)；
- IDA曲线斜率降到弹性段初始斜率的20%。

取两者中**先达到（对应IM较小）**的状态作为LS3/倒塌判据。

因此：

\[
1.25\%H=968.75\text{ mm}
\]

只是LS3的一个上限位移条件；某些地震记录可能因为钢段先发生屈曲或IDA曲线先显著软化，在达到968.75 mm之前就进入LS3。

## 27.11 IDA到底怎么做

IDA = Incremental Dynamic Analysis，增量动力分析。

对一条地震波，不是只算一次，而是：

\[
0.005g\rightarrow0.1g\rightarrow0.3g\rightarrow\cdots
\]

逐级放大强度，反复进行非线性时程分析，直到达到倒塌判据。

每一次计算得到一个：

\[
(IM,EDP)
\]

点。

把同一地震记录的所有点连起来：

\[
\boxed{\text{一条IDA曲线}}
\]

30条地震波就得到一簇IDA曲线。

随后从曲线簇提取：

- 16%分位；
- 50%分位；
- 84%分位；

再进行统计回归和易损性计算。

论文的完整流程为：

**两尺度有限元模型 → 地震动记录 → 定义IM/EDP/LS → 非线性时程 → IDA曲线簇 → 分位线 → 回归 → 易损性曲线。**

![博士论文PDF p119/印刷p107：LS3与IDA方法](evidence/li-zeyu/exact/p119_print107_ls3_ida_method.png)

## 27.12 为什么不用固定步长，而用Hunt&Fill

如果每次固定加0.01g：

- 很准确；
- 但大量区间没有明显性能变化；
- 会浪费巨量计算。

如果每次加0.2g：

- 很快；
- 但可能直接跨过屈服、刚度退化和倒塌临界点。

所以作者采用 Hunt&Fill 不等步长搜索。

基本思想：

- 离关键点远时：增大步长；
- 接近性能突变时：缩小步长；
- 已跨过临界点后：在前后两次强度间继续“填充”搜索。

论文中初始地震动强度取：

\[
\boxed{0.005g}
\]

倒塌判断为：

- IDA曲线斜率降到初始斜率20%，**或**
- 塔架出现屈曲现象。

## 27.13 一个具体地震波是怎样把塔推坏的

作者以PEER 1637记录为例。

分析PGA：

- 0.005g；
- 0.455g；
- 0.872g；
- 1.105g。

### 0.005g

基本完好/弹性基准状态。

### 0.455g

- 混凝土损伤极小；
- 钢塔未发生屈曲；
- IDA曲线斜率与初始阶段差异不大。

### 0.872g

- 预应力混凝土段出现明显损伤；
- 损伤主要集中在**混凝土塔下部**；
- **门洞附近**存在明显集中；
- 尚未达到预设最大拉/压损伤；
- 钢段仍未屈曲；
- 结构未倒塌。

作者特别指出：

> 混凝土损伤降低弹性模量，改变整体刚度，因此IDA曲线斜率明显变化；这说明材料非线性不能忽略。

### 1.105g

此时：

- **钢塔段底部明显屈曲**；
- 混凝土塔底部分位置拉损伤达到作者设定的最大值0.9，即局部已开裂；
- 混凝土受压损伤尚未达到其上限；
- 混凝土段仍保有一定承载能力；
- 最终主导倒塌的是：

\[
\boxed{\text{钢塔段底部屈曲}}
\]

而不是混凝土整体压碎。

此外，混凝土损伤区始终没有越过两尺度模型的实体区域，作者据此反证：

> 当前实体段长度足以覆盖真正的非线性损伤区。

## 27.14 为什么要做16%、50%、84%分位IDA曲线

不同地震波造成的响应离散性很大，所以不能拿某一条地震波当“代表全部地震”。

作者把30条IDA曲线进行统计：

- 50%：中位水平；
- 16%与84%：形成包含约68%曲线的区间。

一个重要结论是：

> 即使在0.22g罕遇地震水平，顶部最大水平位移仍小于约400 mm，尚未达到LS1，说明规范设防水平下安全储备较大。

## 27.15 场地和近场/远场到底有什么影响

作者比较三组地震：

- II类场地远场；
- III类场地远场；
- III类场地近场。

结果总体上：

\[
\boxed{\text{II类场地抗震表现优于III类场地}}
\]

以及：

\[
\boxed{\text{远场表现优于近场}}
\]

也就是近场和较软场地条件更不利。

作者解释这与PCSH塔细长、柔性、基本周期较长有关；不同 \(V_{30}\) 使场地卓越周期不同，进而改变地震能量与塔架模态的匹配程度。

以IDA易损性曲线为例：

### PGA=0.035g

LS1/LS2/LS3超越概率基本均为0。

### PGA=0.10g

III类场地：

- 近场：LS1约0.17%、LS2约0.02%、LS3约0；
- 远场：LS1约0.08%、LS2约0、LS3约0。

### PGA=0.22g

III类场地：

- 近场：LS1约9.03%、LS2约1.63%、LS3约0.49%；
- 远场：LS1约5.67%、LS2约0.86%、LS3约0.31%。

因此在同一场地类别下，近场地震的易损性曲线更陡、失效概率更高。

## 27.16 MSA是什么，与IDA有什么根本区别

MSA = Multiple Stripe Analysis，多条带分析。

IDA思路：

> 对每一条波不断改变强度，得到一整条IM–EDP轨迹。

MSA思路：

> 先固定若干离散IM“条带”，例如某几个PGA水平；在每个PGA条带下用大量地震记录统计是否超越LS，再通过最大似然估计拟合易损性函数。

因此可以把两者想象成：

- IDA：**纵向追踪一条波从弱到强的全过程**；
- MSA：**横向在若干固定强度水平做群体统计**。

---

## 27.17 IDA和MSA谁更“好”

博士论文给出的结论不是简单“MSA比IDA高级”。

二者得到的易损性曲线整体相近，但存在系统差异：

- PGA较低时，IDA结果更保守；
- PGA很高时，MSA结果更保守；
- 两者差异随损伤程度增加而增大；
- 最大差异约可达到 **24%**。

作者将高PGA下差异归因于PCSH塔的主要破坏模式较脆：

> 一旦钢塔段屈曲，IDA中真正进入“破坏后”统计的数据相对少，导致高强度区的IDA超越概率偏低。

因此作者认为MSA在该研究中的可靠性更高。

但代价是：

\[
\boxed{\text{MSA需要更多非线性时程分析}}
\]

表5.10给出的计算响应数量：

| 场地/地震类型 | IDA | MSA |
|---|---:|---:|
| II类场地 FF | 62 | 160 |
| III类场地 FF | 64 | 160 |
| III类场地 NF | 61 | 160 |

所以：

> MSA统计样本更多、代价更大；IDA配合Hunt&Fill明显节省计算量。

## 27.18 第5章最后真正得到的结构结论

博士论文第5章小结可以压缩成五条工程结论：

### ① 规范设防水平下安全储备较大

多遇、设防、罕遇地震下塔架整体均有足够承载能力。

### ② 高阶模态必须关注

前三阶模态都参与地震响应，前两阶尤其明显；钢—混转换附近约2/3塔高处出现明显加速度放大。

### ③ 混凝土损伤区有明确空间集中

主要在：

- 混凝土段下部；
- 门洞附近；
- 钢—混转换/连接附近。

### ④ 最终主导失效不是混凝土压碎，而是钢塔下部屈曲

这说明对于这套优化后的PCSH结构，抗震薄弱点最终转移到了上部钢塔的下端区域。

### ⑤ 设计建议必须针对真实薄弱区

作者建议重点加强：

- 门洞；
- 混凝土塔下部；
- 钢塔下部。

可采用：

- 增强局部配筋；
- 增加关键区域壁厚等。

## 27.19 这一章对当前10 MW论文哪些值得学、哪些不要搬

当前10 MW论文已经明确收敛到**抗风性能与结构优化**主线，因此不应把IDA/MSA硬塞进正文增加工作量。

真正值得学习的是其研究组织方式：

### 可直接学习
- 根据可能破坏模式调整模型分辨率；
- 先用确定性代表工况理解响应，再进入统计分析；
- 明确定义“输入指标—响应指标—极限状态”；
- 多条随机样本不能只看单条结果，要做概率/统计；
- 薄弱部位必须由响应结果自然引出优化变量；
- 关键区精细、非关键区简化。

### 不应直接照搬
- 0.035g/0.1g/0.22g等地震参数；
- 30条PEER地震波；
- LS1/LS2/LS3地震极限状态；
- IDA/MSA；
- 7度设防与III类场地；
- 地震门洞加固结论直接用于风致优化。

对当前论文最有价值的映射是：

**李泽宇：地震样本 → 薄弱部位 → 概率响应 → 结构改进**

对应我们的：

**IEC/湍流风多种子 → 控制工况/DEL → 关键截面与局部响应 → 参数敏感性 → 优化 → 全工况复核**

也就是说，应该学习他的“闭环”，而不是复制他的地震章节。

# 28. 第6章：陆上PCSH塔架风致疲劳动力分析——逐页精读

> 证据范围：博士论文 PDF 文件页138–159（论文印刷页126–147）。所有关键流程均已配原文截图，见 \`evidence/li-zeyu/WIND_FATIGUE_INDEX.md\`。  
> 重要边界：李泽宇采用“Kaimal谱+谐波合成+简化动量理论气动推力+两尺度Abaqus”的路线；本文10 MW主线采用TurbSim/OpenFAST/ROSCO获取整机气动弹性载荷，因此只能继承其疲劳评价框架，不能把其气动荷载方法直接替换到本文。

## 28.1 本章完整闭环

李泽宇第6章的研究链条是：

**长期平均风速概率分布 → 各平均风速下脉动风 → Kaimal目标谱 → 谐波合成随机风时程 → 风轮气动推力+塔身分布风荷载 → 两尺度有限元动力时程 → 关键部位应力时程 → 雨流计数 → 分材料S-N曲线 → 各风速年出现时间加权 → 累积疲劳损伤 → 疲劳寿命。**

这说明“风致疲劳”绝不是只找最大风速，也不是只算一个DEL，而是把**短期随机响应**与**长期风速出现概率**连接起来。

![第6章起始与Weibull概率模型](evidence/li-zeyu/wind-fatigue/p138_print126_ch6_start_weibull.png)

## 28.2 平均风与脉动风

论文把瞬时风速分解为：

\[
U(x,y,z,t)=\bar U(z)+u(x,y,z,t)
\]

其中平均风代表慢变/静力成分，脉动风代表可能与结构自振频率接近的动力成分。

长期平均风速采用Weibull分布描述；高度方向平均风采用幂律风剖面换算。于是存在两个统计层次：

1. **长期层**：一年内不同平均风速出现多久；
2. **短期层**：给定平均风速下600 s内瞬时风怎样随机波动。

![风速概率分布与脉动风谱](evidence/li-zeyu/wind-fatigue/p139_print127_probability_spectrum.png)

## 28.3 Kaimal谱、空间相关与谐波合成

论文列出Davenport、Von-Karman、Kaimal三种顺风向谱，最终依据IEC 61400-1采用Kaimal谱。

作者同时考虑不同空间点间脉动风速的相关性，构造互功率谱密度矩阵，再通过Cholesky分解和随机相位谐波叠加生成各高度点的风速时程。其核心思想为：

\[
S(f)\rightarrow \text{互谱矩阵}\rightarrow \text{Cholesky分解}\rightarrow \text{随机相位}\rightarrow u_i(t)
\]

这与TurbSim的目标一致：生成满足目标谱和空间相关性的随机湍流场，但具体算法和模型并不相同。

![Kaimal谱与谐波合成](evidence/li-zeyu/wind-fatigue/p140_print128_kaimal_harmonic.png)

## 28.4 风轮气动荷载：与本文10 MW路线必须严格区分

李泽宇指出BEM需要叶片翼型、升阻力等详细数据，因此本章采用简化动量理论，将风轮视为无厚度致动盘，通过质量守恒、动量守恒和伯努利关系估计推力。

因此，第6章并不是OpenFAST级整机气动弹性分析，没有同时显式考虑柔性叶片、AeroDyn、ROSCO控制、变桨、转速变化和整机多自由度耦合。

**对本文的结论：保留OpenFAST/ROSCO，不回退到该简化推力模型。**

## 28.5 塔身风荷载与分段

77.5 m塔身被划分成4段，论文图6.4对应高度约为：

- 15.5 m；
- 20 m；
- 20 m；
- 22 m。

每段采用中点风速代表该段，并将塔身风荷载简化为均布荷载：

\[
F(t)=\frac12 C_d\rho U^2(t)A
\]

其中拖曳系数取：

\[
C_d=1.2
\]

![塔身风荷载分段](evidence/li-zeyu/wind-fatigue/p143_print131_tower_wind_load.png)

## 28.6 随机风时程参数与谱验证

作者给出的随机风模拟参数为：

- 时间步长：**0.25 s**；
- 脉动风频率范围：**0–25 Hz**；
- 计算时长：**600 s**；
- 风向：**x方向**；
- 代表工况：额定、切出、极限风速。

生成随机风时程后，作者将计算得到的功率谱与目标Kaimal谱进行对比，作为随机风模拟正确性的验证。

这条原则对本文同样适用：TurbSim风场不能只看时域曲线，还要做目标谱、均值、标准差、湍流强度和空间/网格敏感性检查。

## 28.10 风荷载下的关键部位

论文得到：

- 混凝土最大拉/压应力：**预应力混凝土段顶部**，有应力集中；
- 普通钢筋最大应力：**背风面混凝土—法兰连接附近**；
- 预应力筋最大应力：**迎风面**；
- 钢塔最大应力：**钢塔段底部背风面**。

因此钢—混转换/法兰连接区域从静力、动力到疲劳都反复成为关键区域。

## 28.11 风与地震的控制模态不同

因此同一结构在不同荷载下的控制模态并不相同：

\[
\boxed{\text{风致响应主要由一阶模态控制；地震响应高阶模态更重要}}
\]

# 29. 第6章疲劳部分：从应力时程到寿命

## 29.1 为什么主要研究正常运行风速

论文引用既有研究认为，风机塔架约99.5%的疲劳损伤来自正常运行状态，因此重点研究：

\[
3\sim25\text{ m/s}
\]

并离散为11个代表风速工况：

\[
4,6,8,\ldots,24\text{ m/s}
\]

论文还指出20年内应力循环可达到约：

\[
5.29\times10^8
\]

属于高周疲劳问题。

![疲劳方法引入](evidence/li-zeyu/wind-fatigue/p149_print137_fatigue_method_intro.png)

## 29.2 李泽宇的疲劳目标不是load-DEL，而是材料寿命

其最终目标是：

\[
T_f=\text{疲劳寿命（年）}
\]

所以必须进入材料局部应力层级：

**风况 → 荷载时程 → 两尺度有限元 → 关键位置应力时程 → 雨流计数 → S-N曲线 → 累计损伤 → 疲劳寿命。**

这与本文已有的load-level DEL必须区分：

\[
DEL=\left(\frac{\sum n_i(\Delta L_i)^m}{N_{eq}}\right)^{1/m}
\]

DEL适合做载荷通道/工况筛选，但不能直接回答某个混凝土、PT或焊缝还能使用多少年。

![疲劳流程与损伤公式](evidence/li-zeyu/wind-fatigue/p150_print138_fatigue_flow_rainflow.png)

## 29.3 雨流计数的位置

随机应力时程：

\[
\sigma(t)
\]

经雨流计数转成：

\[
(\Delta\sigma_i,n_i)
\]

再根据S-N关系得到对应允许循环次数 \(N_i\)，最终进入累计损伤。

论文还对低应力区疲劳损伤作修正，不是把所有低幅循环直接删除。

## 29.4 不同材料使用不同S-N关系

### 混凝土

按应力状态分别处理：

- 全受压；
- 拉压；
- 全受拉/特定拉压状态。

因此混凝土疲劳不仅取决于应力幅，还受平均/参考应力水平影响。

### 普通钢筋

依据CEB-FIB采用钢筋S-N关系，并按直径区分转折点应力：

- \(d\le16\) mm：约210 MPa；
- \(d>16\) mm：约160 MPa。

### 钢塔/焊缝

钢塔底部—法兰连接区域采用DNV相关S-N曲线，为典型双斜率形式。

这进一步证明本文Ch4必须遵守：

\[
\boxed{\text{concrete/PT/steel不得统一使用一个m值或一条S-N曲线}}
\]

## 29.5 疲劳关键位置怎么选

作者不是整塔无差别计算，而是依据前文应力集中和结构构造选择：

1. 钢塔底部—法兰连接区域；
2. PC段顶部背风面；
3. PC段底部背风面；
4. 预应力筋；
5. 门洞上部；
6. 门洞下部。

钢塔底部与法兰连接的对接焊缝热影响区被视为薄弱区；论文采用的一个参照值是：

- \(2\times10^6\) 次循环对应疲劳容许应力幅约 **71 MPa**。

## 29.6 为什么普通纵筋和高强螺栓不是主要疲劳对象

论文认为，若预应力混凝土塔保持全截面受压，则普通纵筋不承受显著反复拉应力，因此不作为主要疲劳验算对象。

高强螺栓则以“预紧力维持在设计范围内时，外荷载引起的实际应力波动较小”为依据，没有作为主要疲劳控制对象。

两者都属于**有条件成立的简化**，不是本文可以无条件照搬的规则。若T057后续真实局部应力表明普通纵筋出现拉应力循环、接缝开张或螺栓应力幅显著，则必须另行验算。

## 29.8 长期风速概率如何进入疲劳

作者根据平均风速概率分布，将不同短期工况折算为一年累计出现时间。

表6.3：

| 风速 m/s | 年累计时间 h |
|---:|---:|
| 4 | 3835.62 |
| 6 | 2659.25 |
| 8 | 537.69 |
| 10 | 25.48 |
| 12 | 0.21 |
| 14–24 | 表中四舍五入为0.00 |

因此长期损伤实质上是：

\[
D_{\rm year}=\sum_j p_jD_j
\]

也就是说，**高风速应力大但概率低，中低风速循环多，长期疲劳不能只看极值。**

## 29.10 为什么PC段顶部比塔底更控制疲劳

虽然整体弯矩通常在塔底最大，但PC段顶部靠近钢—混转换、法兰和预应力锚固区域，存在明显局部应力集中。

因此：

\[
\boxed{\text{疲劳控制位置不能只按全局弯矩大小判断，还必须看局部构造应力集中}}
\]

这正是两尺度方法的价值：纯中心线梁模型可能捕捉不到真正控制寿命的局部区域。

## 29.11 结构改进建议

作者针对PC顶部/法兰附近的疲劳控制问题建议：

- 更换/优化法兰形式；
- 加厚连接法兰。

门洞因为设置80 mm钢板，风疲劳下的应力集中被显著削弱，寿命远高于20年。

注意：第5章地震强非线性下门洞仍是损伤集中区；第6章常规风疲劳下门洞经过钢板加强后不是寿命控制点。**不同荷载机制下薄弱位置可能不同。**

# 30. 李泽宇第6章对本文10 MW五章制路线的直接作用

## 30.1 可以直接继承的研究思想

本文应继承：

- “长期概率 + 短期随机响应”的两层疲劳框架；
- 先通过全局载荷筛选，再进入局部应力；
- 疲劳关键位置由真实应力集中和结构细节确定；
- Rainflow必须作用于材料局部应力时程，才能进入材料S-N/Miner；
- 混凝土、PT、钢塔/焊缝采用不同疲劳模型；
- 连接/转换区需要比普通塔身更高的局部分辨率；
- 结果必须形成“控制位置 → 机理 → 设计改进”的闭环。

## 30.2 不能直接照搬的内容

本文不能直接复制：

- 李泽宇的77.5 m / 2 MW结构参数；
- 其4段塔身风荷载离散；
- \(C_d=1.2\) 作为本文整机主气动模型；
- 简化致动盘推力替代OpenFAST；
- 其Weibull参数与各风速年小时数；
- 其20.42年、24.66年寿命数值；
- 其具体S-N参数直接用于T057而不核对材料/细节类别；
- “普通纵筋一定不用做疲劳”“螺栓一定无疲劳”等条件性判断。

## 30.3 本文已有能力比李泽宇更强的部分

本文已经具备：

- TurbSim随机湍流场；
- OpenFAST v3.5.3；
- ROSCO控制；
- DTU 10 MW整机气动弹性；
- 多风速、多湍流模型、多seed；
- 700 s时程并舍弃前100 s；
- load-rainflow / load-DEL；
- T057精细Abaqus候选；
- 分材料疲劳路线。

所以论文不应该退回李泽宇的简化风轮推力，而应在他的疲劳闭环基础上向前走。

## 30.5 T057后续优先布置的局部疲劳区域

结合李泽宇第6章与当前T057结构，应优先闭合：

- 钢塔底部/钢—混转换段；
- 转换段法兰与锚固附近；
- PC塔顶部迎风/背风侧；
- PC塔底部；
- PT迎/背风侧；
- 门洞（若T057几何实际包含且证据闭合）；
- 普通纵筋最不利区域（仅在局部应力显示需要时）。

但在执行Ch4之前仍必须完成当前总控规定的门禁：

**T057 native Data Check → Gravity/PT/contact equilibrium → mass/CG/J → Modal/Flex → 必要网格收敛 → Ch3数据身份与DLC1.2 bins → Ch4 local material fatigue。**

这也是李泽宇论文真正值得学习的地方：不是“把疲劳章节写出来”，而是先确保**载荷、模型、局部应力和材料疲劳模型之间的证据链闭合**。
