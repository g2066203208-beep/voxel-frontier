## 对 Abaqus 配筋模型的使用原则

- 风机混塔专用设计优先核对 NB/T 10907-2021。
- 普通钢筋具体构造/配筋计算采用现行 **GB/T 50010-2010（2024修订）**，同时满足上位强制性通用规范。
- 预应力钢绞线材料规格核对 GB/T 5224-2023。
- 塔架总体极限状态、疲劳及接口设计核对 GB/T 42600-2023。
- “何泽瑜模型原参数”“同研究团队论文参数”“现行规范重构参数”必须分栏记录，不得互相冒充直接来源。
