# T089｜水平接缝独立算法核：C++17数学原型与直接二次开发文献

**状态：独立算法代码与数学测试；不是Abaqus子程序、不是经试验验证的混凝土接触本构。** 该目录属于GitHub Actions可独立测试的非Abaqus研究工作；原158m模型与真实求解数据一律不改。

## 代码位置与实际功能

- `interface.hpp`：材料点输入、SI单位、界面历史变量；法向间隙、法压、二维切向牵引与累计滑移。
- `interface.cpp`：法向单边受压罚函数，二维切向试算—黏着/滑移判断，库仑恒μ返回映射；另设**纯合成、未标定**的随累积滑移指数弱化候选律。
- `tests.cpp`：24项数学断言，检查法压、摩擦极限、滑移增量、反向加载、开缝后卸除切力、状态历史、向量方向与参数域拒绝。
- `example.cpp`：只导出15步合成加载CSV，**绝对不是期刊试验曲线**。
- `.github/workflows/t089-interface-benchmark.yml`：研究分支上用Ubuntu/g++ C++17编译、测试、保存合成CSV。

数学基准为 `p=k_n max(0,-gap)`、`tau_trial=tau_old+k_t Δs`、`||tau||≤μp`，滑移返回映射需满足 `||tau_trial||−k_tγ−μ(s_acc+γ)p=0`。候选 `μ(s_acc)=μ_r+(μ_p−μ_r)exp(−s_acc/s0)` **不是首次提出的新规律，更不是已验证的混凝土水平缝物理本构**。不具备真实法切向损伤、接缝几何、PT锚固、FE接触搜索、全局切线矩阵及全塔平衡解。

## 实验验证与创新门槛

T089仅能证明数学软件在指定域内的断言是否通过。真正可发表的“比传统内置接触更准确”必须经过：真实水平缝构造识别；不同法压/滑移/循环历史的独立试验数据；训练和留出分开；对恒μ、Abaqus内置压力/速度依赖摩擦均进行公平对照；量化误差、置信区间、参数可辨识性。任何一关未通过，都不宣称新的本构优于已有模型。
