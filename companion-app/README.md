# 小栖 · Companion v0.1

Android prototype for a phone companion / virtual friend.

## Implemented
- Layered procedural 2D puppet rather than a single static sprite
- breathing, blinking, head sway, eye tracking and arm wave animation
- direct touch interactions: tap, double tap, long-press/pet, body tap, background gaze
- time-of-day greetings and idle proactive behaviors
- lightweight persistent memory: recent conversation, visit count and relationship stage
- local offline dialogue prototype with mood reactions
- day/night room ambience
- minimal companion-first UI with chat / quiet company / pose actions

This first build intentionally avoids cloud AI dependencies so the interaction and character-presence loop can be tested offline.
