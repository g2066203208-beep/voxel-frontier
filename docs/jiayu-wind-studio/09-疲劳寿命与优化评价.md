# 疲劳寿命与优化评价报告

> JY-FAT-09

## 载荷—材料链
- 载荷时间序列、同源时间窗、风况概率与 seed 样本。
- 雨流循环（范围/均值/次数）、DEL^m、Neq 参数。
- 应力转换、均值应力效应、材料疲劳曲线、Miners法则等，应分别给出可核文献。

## 核心误用防线
1. 载荷 DEL 不是材料寿命。
2. DEL^4 不自动等于原始载荷时间序列 M(t)^4 矩。
3. 稀疏高风箱和零观测尾部不能未经假设直接推出有限年化四次矩上界。
4. 有限 seed 筛选不能代表符合全DLC要求。
5. 数值统计误差与未收敛的物理模型误差分开汇报。

## 优化方案
变量、尺寸/材料边界、目标函数、约束、试验设计、鲁棒性、交叉验证、Pareto验证和结论不确定性。

## 输出
循环账本、源SHA、统计图、算式与审核表、材料适用性和结果可重复性说明。
