# 混合塔架结构与材料调查报告

> JY-STR-06

## 结构体系
塔架设计原型与工程场址分开定义；混凝土塔段、钢塔段、预应力体系、配筋、塔顶机组与基础连接。

## 资料登记
| 对象 | 参数 | 证据状态 |
| --- | --- | --- |
| 几何 | 高度/直径/壁厚/节段划分 | 原始模型、来源文献 |
| 混凝土 | 等级、弹性、强度、徐变收缩 | 文献/报告 |
| 钢材 | 材料参数、板厚、连接 | 图纸/规范 |
| 预应力 | 钢绞线、张拉、损失、有效值 | 设计支路 |
| 配筋 | 纵筋/箍筋/节点定位 | 31段归档和来源 |
| 接缝 | 干接缝/摩擦/灌浆/螺栓 | 真实构造资料 |

## 必要说明
- 文献原型参数不得与后续设计支路混称；
- T077/T078有研究性设计数据，不等于所有结构极限状态通过验收；
- 只按用户授权的实际工作分工处理 Abaqus，不新增本助手 Abaqus 执行任务。
