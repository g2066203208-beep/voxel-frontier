# 湖北嘉鱼区域风机研究｜前期资料核验简报

> JY-BG-00 · 版本 v1.0.1 · 2026-11-13 · 证据等级：公开资料背景核验（非工程现场勘察）

## 研究对象与资料范围
- 地理背景：**湖北省咸宁市嘉鱼县**。嘉鱼是否为真实风机机位所在地尚无本简报所能证实的工程审批、坐标或勘察文件。
- 对象：科研仓库中以 **10 MW级、158 m预应力混凝土—钢混合塔架**为代表的学术研究原型；与嘉鱼县真实风场工程不能自动等同。
- 本简报只构成“区域背景／前期资料调查”；不能作为风电场选址、地质勘察、抗震设防参数或环评的完成证明。

## 一、已核验区域背景
| 专题 | 公共来源核实的情况 | 工程解释边界 |
| --- | --- | --- |
| 区域位置 | 嘉鱼县位于湖北省咸宁市、长江中游南岸，滨江含湖。 | 可以说明区域宏观地形水文背景，不能推导机位坐标 |
| 地表水环境 | 湖北省农业农村厅公开资料描述嘉鱼水网密布、30%版图为江河湖泊。 | 需调查洪涝、水位、地下水和基础设计要求，不能据此给出机位地下水位 |
| 区域气候 | 中国天气网“嘉鱼城市介绍”提到咸宁为亚热带湿润季风气候、夏季降水集中，梅雨期强降水较多。 | 地区气候描述不能替代逐时轮毂高度风资源测量 |
| 风资源数据 | ECMWF/Copernicus ERA5 提供逐小时再分析数据及约0.25°常规经纬网格。 | 再分析不能当成机位实测；需要测风、位置及高度订正 |
| 地震信息 | GB 18306—2015为现行《中国地震动参数区划图》；实际设计值须按精确工程位置、场地类别及适用规定判定。 | 本简报不提供任何未经核验的PGA、场地特征周期及设防烈度 |

## 三、待取得的一手材料
1. 风机实际项目名称、风电场及机位坐标（WGS84/CGCS2000等）与测量基准；
2. 可用测风塔/激光雷达原始记录、测站高度、校准及有效率；
3. 地形DEM、场址地形图、地下水/洪涝及基础勘探钻孔；
4. 土层动力参数、场地类别、建设工程地震评价文件；
5. 风机额定参数、机组控制逻辑、基础顶动力输入接口；
6. 管理许可、环境影响资料、道路/施工及电网接入约束。

缺少以上资料时，不得给出“已完成选址”“实测风速”“嘉鱼设计地震波”等工程性结论。
