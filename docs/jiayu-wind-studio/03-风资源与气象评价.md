# 风资源与气象评估研究报告

> JY-WIND-03 · 方法模板，不代表站点已通过风资源评估

## 数据来源
- ERA5 的格点范围、经纬度、时区、变量、逐小时时段、版本、DOI：10.24381/cds.adbb2d47。
- 机位实测资料：测风塔/激光雷达设备、安装高度、有效率、校准记录，若没有请填写“未取得”。
- 数据清洗与天气年份划分：缺测、异常、平稳性、风向定义。

## 分析顺序
1. 100 m/轮毂高度风速风向时序、玫瑰图、年度差异。
2. 风速分箱、风向扇区、Weibull/经验分布对照。
3. 极端风、湍流、风切变、空气密度和不确定性。
4. ERA5与地面/机位观测差异；不能无验证地将再分析等同场址。
5. 风况权重、空箱、稀疏尾部事件与不确定性上界。
