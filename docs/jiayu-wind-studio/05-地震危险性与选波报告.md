# 地震危险性与真实地震动选波报告

> JY-SEIS-05 · 未确认场址地勘、地震参数及最终选波前，不写入拟合结果

## 1. 地震设计参数
工程精确位置、场地类别、设防要求、GB 18306—2015 区划信息、GB 55002—2021 适用性，记录官方依据及生效版本。

## 2. 候选记录信息表
| 字段 | 要求 |
| --- | --- |
| 事件 | 日期、震级、震源深度、距震 |
| 台站 | 台站名、代码、经纬度、场地参数 |
| 记录 | 水平1/水平2/竖直分量、采样率、总时长 |
| 来源 | PEER/官方台网/地震目录，授权和原始文件SHA |
| 处理 | 校正、滤波、截断、单位转换、旋转、缩放 |
| 评价 | PGA、PGV、PSA、反应谱、RotD、长周期保真度 |

## 3. 抗震响应方案
- 比较：固定底参考与基础顶部输入，定义严格一致的边界条件；
- 地震动的物理量输入位置和自由度以模型接口为准；
- 风—震配对须同步初态与载荷归属，不直接拼接峰值；
- 保留实测记录处理及敏感性图。

## 4. 结论准入
仅当原始记录、场址参数、处理谱和复核全部可回溯，才给出可用地震波。**不要把嘉鱼县风资源网格位置自动当成地震工程场址。**
