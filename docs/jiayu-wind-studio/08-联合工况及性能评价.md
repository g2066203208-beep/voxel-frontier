# 风—震联合工况及性能评价报告

> JY-WE-08

## 研究问题
单风 W、单震 E、基准 B、联合 WE 在同一个结构状态和可比较初始条件下的响应差异。

## 组合矩阵
| 条目 | 主要门禁 | 说明 |
| --- | --- | --- |
| B | 重力/有效预压/初态来源 | 基准 |
| W | 同源风速、控制、六分量和坐标 | 不以峰值代时序 |
| E | 真实地震波、基底输入与场地准入 | 记录和处理可复查 |
| WE | W/E的时间、状态、初态、参考点统一 | 正式耦合需另行准入 |

## 性能评价
塔顶位移/加速度、底部弯矩/剪力、材料关键点需求、动力放大、损伤、恢复力和失效模式；所有量纲单列。

## 数据与结论等级
SOURCE原件 → 方法复算 → 同源可比工况 → 独立验证 → 正式科研结论。任何未完成门槛为 HOLD。

参考：T080 联合工况研究记录和最新版论文缺口清单。
