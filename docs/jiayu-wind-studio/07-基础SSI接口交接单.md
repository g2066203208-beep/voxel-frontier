# 基础与土—结构相互作用（SSI）接口交接单

> JY-SSI-07 · 适用于合作方移交基础顶部动力时程，非 SSI 求解结果

## 1. 模型和责任边界
- 负责SSI分析的协作者：
- 接收塔架子系统的负责人：
- 地基与基础模型身份/版本：
- 塔架与基础耦合界面、控制点：

## 2. 数据定义
| 项 | 需提交 |
| --- | --- |
| 坐标系 | x/y/z定义、局部/全局、右手系 |
| 自由度 | UX/UY/UZ、RX/RY/RZ是否包含，约束耦合方式 |
| 时程 | 加速度/速度/位移、采样率、起止时间、单位 |
| 基础信息 | 截面参考面、桩/承台/垫层、埋深、输入位置 |
| 边界 | 固定参考/柔性基础、地基假设和动力转换 |
| 记录 | 地震事件、台站、方向、处理谱/缩放 |
| 核验 | 质量守恒、平衡、归一性、方向、时域长度 |

## 3. 准入检查
- 同一自由度不能重复约束或重复施加；
- 不将锚栓节点的局部受力替代为地震地面运动；
- 固定底和柔性基础两条方案的物理解释、对照目标明确；
- 仅在数据符合交接门槛后开展一致性比较。

## 4. 交付物
数据文件、metadata.json、处理脚本、SHA、版本日志、验收签字。
