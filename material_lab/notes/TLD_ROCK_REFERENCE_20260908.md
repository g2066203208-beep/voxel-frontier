# Rock reference lock — 2026-09-08

Reference target: the chunky, painterly rock massing visible in Hinterland's official *The Long Dark* environment imagery.

Implementation guardrails for `VF_PAINTERLY_PLANETARY_V1`:

- the base shell must remain visibly lower than hero rock masses;
- support blocks may close gaps, but may not flatten the silhouette into a sphere;
- hero blocks must visibly break the underlying spherical silhouette under true Height displacement;
- hero blocks use broad, thick chamfered shoulders rather than thin fins;
- top faces are large, angular painted planes with limited micro-noise;
- cracks are narrow and deep, not broad empty belts;
- warm ochre/light planes contrast against cool purple/blue shadow planes;
- no generated image assets are production sources; references guide procedural code only.
