# Voxel Frontier

原创浏览器体素沙盒游戏，从零开发，不依赖 Minecraft、NeoForge 或任何原版资源。

## 当前可玩版本

- 程序化体素地形
- 第一人称移动、冲刺、跳跃与重力
- 方块碰撞
- 射线破坏/放置方块
- 5格快捷栏与方块切换
- 树木、雾效、天空和基础光照
- GitHub Pages 自动部署

## 操作

- 点击游戏画面：捕获鼠标
- W A S D：移动
- Space：跳跃
- Shift：冲刺
- 鼠标：观察
- 左键：破坏方块
- 右键：放置方块
- 1–5 / 滚轮：切换方块
- Esc：释放鼠标

## 项目方向

这是独立游戏项目，不再是 Minecraft Mod 工程。后续按模块继续扩展：区块流式加载、存档、背包、合成、实体、NPC、城市、车辆、天气、多人联机以及自定义 Mod API。

网页源文件位于 `web/`。GitHub Pages 工作流位于 `.github/workflows/pages.yml`。
